# INNO Analytics — 사용 가이드

STEM / TEM / EDS 데이터 분석용 단일 파일 플랫폼. Velox `.emd` · Gatan `.dm3`/`.dm4` ·
TIFF · MRC · Bruker `.bcf` 를 브라우저에서 **직접** 파싱하며 어떤 데이터도 외부로 전송하지 않는다.

## 화면 구성

**파일 목록은 탭이 아니라 왼쪽 상시 열이다.** 탭으로 두면 "지금 어느 파일을 보고 있는지"가
화면에서 사라지고, 파일을 바꾸려면 탭을 두 번 오가야 한다.

- **파일명을 줄여서 표시하지 않는다** — 배율·시료 번호가 이름 끝에 붙어 있어 말줄임하면
  정작 구분에 필요한 부분이 사라진다. 세로로 나열하고 필요하면 줄바꿈한다.
- 좁은 화면(≤900 px)에서는 겹쳐 뜨므로 접힌 상태로 시작한다.
- 파일을 닫을 때 HDF5 가상 파일시스템까지 비운다 — 안 그러면 WASM 힙에 그대로 남는다.

> **화면 문구 원칙**: 눌러 보면 알 수 있는 조작법은 적지 않는다. 화면에 남긴 글은
> **출처**(이 값이 어디서 왔는가)와 **함정**(무엇이 조용히 틀릴 수 있는가) 두 가지뿐이다.

## 읽는 파일 형식

| 형식 | 장비 | 화소 크기(교정) | 비고 |
|---|---|---|---|
| `.emd` | Talos / Velox | 메타데이터에 그대로 | EDS·SI 포함 |
| `.dm3` / `.dm4` | Tecnai / Gatan DM | **교정 태그에서 직접** | 원본 계조(int32 등) |
| `.tif` / `.tiff` | DM 내보내기 등 | **Gatan 개인 태그에서 되짚음** (아래) | 8비트 표시용 사본인 경우가 많음. RGB 8-bit 는 밝기(Rec.601) 한 채널로 읽음 |
| `.mrc` `.mrcs` `.st` `.rec` `.ali` | Velox / EPU / Glacios 등 | **CELLA / MX** (MRC 표준) | int8·int16·uint16·float32·float16·복소 |
| `.bcf` | Bruker | 헤더에서 | EDS 하이퍼맵 |

### MRC — 화소 크기와 방향을 어떻게 확신하는가

MRC 헤더는 1024바이트 고정이고 화소 크기는 `CELLA / MX` 에서 나온다(단위 Å).
바이트오더는 `MACHST` 도장으로 정하고, 도장이 없는 옛 파일은 머리 값이 말이 되는 쪽을 고른다.

**같은 취득이 `.emd` 와 `.mrc` 로 둘 다 남아 있어 직접 대조할 수 있었다.**

| 항목 | 결과 |
|---|---|
| 화소 크기 | emd 41.1511 pm == mrc 41.1511 pm |
| 화소값 | **완전히 동일** (표본 최대 차 0) |
| 행 순서 | 그대로 상관 **1.000000**, 상하 반전 −0.0215 → **뒤집지 않는다** |
| 격자 d 측정 | emd·mrc 가 소수점 끝까지 동일 (2.9673 Å / 1.4822 Å) |

행 순서는 MRC 관례(결정학은 아래에서 위)와 현미경 관례(위에서 아래)가 갈리는 지점이라
**추측하지 않고 실측으로 정했다.**

FEI/Thermo 는 `EXTTYP='FEI1'/'FEI2'` 확장 헤더에 자체 메타데이터를 넣는데, **그 스키마를
검증하지 못했으므로 화소 크기는 표준 헤더에서만 가져오고** 확장 헤더에서는 읽을 수 있는
문자열(장비·검출기 이름)만 기회적으로 뽑는다. 검증 못한 오프셋에서 숫자를 꺼내 쓰면
조용히 틀린 값이 된다.

### TIFF 의 화소 크기는 어떻게 얻는가

DM 이 내보낸 TIFF 의 `XResolution` 은 **72 dpi 라는 무의미한 기본값**이라 쓸 수 없다.
대신 Gatan 은 개인 태그 `65027` 에 DM 태그 트리를 통째로 심어 둔다. 거기 `Actual Magnification`
이 있으므로

```
화소 크기 [nm] = (카메라 물리 화소 [µm] × 1000 × 비닝) / 실제배율
```

로 되짚는다. 카메라 물리 화소는 **이름별 등록부**에서 찾고, 등록에 없으면 **추측하지 않고
"모른다"고 말한다** — 여기서 임의값을 넣으면 d 가 조용히 틀린다.

**검증**: 같은 시료의 `.dm3` 교정값과 대조했다.

| 파일 | dm3 교정 | TIFF 에서 되짚음 |
|---|---|---|
| 400 kx 표시 (실제 519695) | 0.026939 nm/px | **0.026939** |
| 195 kx 표시 (실제 253351) | 0.055259 nm/px | **0.055259** |

> **표시배율과 실제배율은 다르다.** 파일명의 `350000x` 나 DM 의 `Indicated Magnification` 은
> 화면 기준이고, 카메라 평면의 `Actual Magnification` 은 그보다 30% 정도 크다. d 계산에는
> **반드시 실제배율**을 써야 한다. 앱이 무엇을 썼는지는 격자 탭 상단에 항상 표시된다.

### 8비트 TIFF 는 격자 측정에 써도 되는가

DM 이 내보낸 TIFF 는 보통 **8비트 팔레트**다(원본 dm3 는 int32). 같은 이미지를 두 형식으로
읽어 같은 자리에서 잰 결과:

| | dm3 (int32) | tif (8bit) | 차이 |
|---|---|---|---|
| d₁ | 1.9543 Å | 1.9543 Å | 0.000% |
| d₂ | 1.6529 Å | 1.6527 Å | 0.012% |
| d₁ (다른 파일) | 3.2777 Å | 3.2776 Å | 0.003% |

**줄무늬의 위치는 계조 양자화에 거의 영향받지 않으므로 d 측정에는 문제가 없다.**
다만 약한 스폿의 대비는 손해를 보므로, 원본 `.dm3` 가 있으면 그쪽이 낫다.

## 실행

`INNO Analytics.html` 을 브라우저로 열기만 하면 된다. 설치·서버·인터넷 불필요.
HDF5 엔진(NIST h5wasm, WebAssembly)이 파일 안에 내장되어 있어 오프라인에서 동작한다.
파일 크기가 약 5.9 MB 인 것은 그 때문이며, "파일 하나만 있으면 동작" 원칙은 NanoLab 과 같다.

## Diffraction — SAED 사용 순서

1. 회절 이미지(.dm3·.dm4·GMS .tif)를 연다 → Diffraction 탭이 SAED 로 열리고 바로 분석한다(스폿/링 자동 판정, 큰 이미지는 몇 초).
2. **Calibration**: 파일 태그(1/nm)가 있으면 그것, GMS tif 면 그림 속 스케일바의 길이(px)와 이름표 숫자("5 1/nm" 등)를 읽어 채운다 — GMS 기본 이름표(검은 명조 글자 + 흰 그림자, 속 빈 흰 막대)도 읽는다(2026-10-17). 확신이 낮으면 주황으로 알리니 그림과 맞는지 확인한다. 표준 시료(Au·Al 링, Si 단결정)로 만든 **Saved** 보정이 가장 정확하다.
3. 결과: 스폿이면 R1·R2·R3(REDI 규약: ∠R1·R2 둔각, R3 = 짧은 대각선)의 d·각도와 불확도, 링이면 링별 d.
4. **Phase ID**: EDS 로 확인한 원소를 넣고 Search. 조성비를 알면 수까지 넣는다(REDI 의 성분·조성비) — `Fe3 O4` · `Fe3O4` · `Fe=42 O=58`(EDS at.%) → 넣은 원소끼리의 몫이 **Ratio ±**(기본 5 at.%p) 안인 상만 후보. 세기 비교는 기본이 동역학(Bloch-wave — 이중 회절로 생기는 스폿·Gjønnes–Moodie 소멸 반영, Intensities 에서 Kinematic 으로 바꿀 수 있음). 표는 Score 순(설명은 표 아래). 파일 태그·스케일바 보정은 공칭값이라 순위에 쓰지 않고 κ 만 보여 준다(초록 = 허용 안). 행을 누르면 그림에 지수·빠진 반사가 겹친다.
5. 표준 시료면 **Use as calibration** → 장비·카메라 길이별로 저장(이 기기 / 연구실 DB). 다음부터 Calibration → Saved.
6. 중심이 틀렸으면 **Set center** 로 직접빔을 누른다(근처 Friedel 중심으로 다듬음). 겹친 상이 있으면 **Use spots: Strongest N** 이나 Lattice 1/2 탭.
7. 후보 표는 R1·R2·R3 의 hkl·계산 d·Δd 와 세 각도(∠R1·R2 / ∠R1·R3 / ∠R2·R3, 괄호 = 계산 − 측정)를 보여 준다(REDI 결과 패널과 같은 항목).
8. 내보내기: CSV(스폿·지수·d, R1–R3·각도 비교), PNG(그림+겹침), **Export report**(그림 + 결과 패널 한 장 — REDI 의 이미지 저장·결정정보 저장), JSON(사용한 DB 항목 id·판 포함 — 나중에 재현).

실측 확인 예: 같은 Libra 200 의 DM 태그가 Au 링 기준 약 9 % 작았고(κ 1.09), 300 mm 에서는 투사 렌즈 찌그러짐 7 % 가 있었다 — 표준 보정을 저장해 두는 이유.

## 화면

화면 이름(탭·제목·메뉴·버튼)은 영어, 설명·알림·경고는 한국어다(2026-10-17). 휴대폰에서는 아래 탭이 짧은 이름(괄호)으로 보인다.

| 탭 | 내용 |
|---|---|
| **XPS** (XPS) | XPS 피팅·대전 보정·정량·Auger parameter·survey |
| **Files** (왼쪽 열) | 전자현미경 파일을 드래그&드롭 또는 선택. 여러 개 동시. 각 파일의 Image / Spectrum / SpectrumStream 개수 표시 |
| **EM Image** (EM Img) | 위쪽 **Image · Metadata** 전환 — Metadata = 파일 구조 트리, 전체 메타데이터 검색, acquisition log(옛 EM Metadata 탭; 이미지가 없는 파일은 바로 Metadata). 연 전자현미경 파일(Velox EMD·DM·BCF·MRC·TIFF)의 S/TEM·SEM 상 뷰어 — 대비·감마·컬러맵, 보정된 스케일바, 거리·라인 프로파일, ROI 통계·ROI 스펙트럼, 내보내기 |
| **Image Analysis** (Analysis) | ImageJ 방식 범용 이미지 분석 — 광학 현미경(ND2·CZI·LIF·OIR)·AFM(IBW·GWY·Nanoscope)·SEM·TEM 이미지 모두. 이 탭은 자체 파일 목록을 쓴다 |
| **EDS Maps** (Maps) | 원소별로 색을 골라 기준 상 위에 겹쳐 보기. 스트림에서 맵을 직접 계산 |
| **EDS Spectrum** (Spectra) | 에너지 보정, 원소 라인 주석, 피크 검출, 자동 원소 식별, 정량 |
| **Diffraction** (Diffr.) | 세 모드 — **FFT (HRTEM)**: HRTEM 의 FFT 로 d-spacing·마스크 역FFT (옛 Lattice FFT) · **SAED**: 회절도(스폿·링) 자동 읽기, 보정(파일 태그·스케일바·저장한 표준 보정), 상 찾기(원소·내장/연구실/이 기기 Phase DB), 수동 비교, 보정 저장 · **Phase DB**: 결정상 목록·CIF 가져오기·연구실 공유(구글 로그인) |
| **EDS Interference** (Interf.) | 선택 원소들의 방출선이 검출기 분해능 안에서 겹치는지 판정 |
| **Energy Diagram** (Energy) | 란탄족 에너지 준위 도식·에너지 전달 판정 |
| **DRE Kinetics** (DRE) | rate equation 시뮬레이션·피팅 |

탭 막대는 늘 한 줄이다(데스크톱): 전체 이름이 안 들어가면 괄호 안의 짧은 이름으로, 그래도 넘치면(창이 아주 좁거나 화면 확대) 뒤쪽 탭이 오른쪽 **More ▾** 메뉴로 들어간다 — 지금 보는 탭은 늘 막대에 남는다. 휴대폰은 아래 고정 막대.

라이트/다크 테마는 우측 상단 칩으로 전환하며 선택은 브라우저에 기억된다.
처음 열 때는 OS 설정을 따른다.

### 휴대폰·태블릿 (손가락)

모든 이미지·그래프 캔버스(EM Image, EDS Maps, EDS Spectrum, Diffraction 의 FFT·SAED, Image Analysis, XPS)에서 같은 손짓이 통한다(2026-10-17).

| 손짓 | 동작 |
|---|---|
| 두 손가락 벌리기·오므리기 | 두 손가락 가운데를 중심으로 확대·축소(스펙트럼은 에너지 축만). 어느 도구를 고른 상태든 두 손가락은 언제나 확대·이동 |
| 한 손가락 끌기 | 보기 이동. 단 그리기 도구(Image Analysis 의 Rectangle·Oval·Polygon·Freehand·Line·Angle·Set Scale, EM Image 의 Distance·ROI)를 고르면 그 도구로 그린다 |
| 두 번 탭 | 화면에 맞춤·처음 보기 |
| 탭 | 마우스를 올렸을 때 보이던 값: 화소 값(EM Image 위 읽기 칸, Image Analysis 상태 줄), XPS 값 풍선 |
| 길게 누르기 | 값 읽기 — 손가락을 떼지 않고 움직이면 따라간다 |

- 그리는 중에 둘째 손가락을 대면 그리던 것은 취소되고 확대·이동으로 넘어간다.
- Image Analysis: Polygon 은 꼭짓점마다 탭하고 캔버스 아래의 **Finish**(또는 첫 꼭짓점을 다시 탭)로 닫는다. ROI 손잡이는 손가락용으로 크게 보이고 잡힌다. Point·Wand·Zoom 도구는 탭 한 번이 클릭 한 번, Point 도구에서 점을 길게 누르면 지운다(마우스의 Alt+클릭).
- XPS: **+ Add component** 를 누른 뒤 그래프를 탭한 자리(BE, 높이)에 성분이 놓인다. 성분 꼭대기 표지·영역 손잡이는 한 손가락으로 끈다.
- Lattice FFT: 확대한 FFT 위를 탭하면 그 자리 스폿을 잰다(클릭과 같음). 실공간 탭은 FFT 영역 옮기기.
- 확대 상태는 화면에만 있고 저장되지 않는다. 손짓을 받는 캔버스 위에서는 쪽이 스크롤되지 않으니 캔버스 밖을 끌어 스크롤한다.
- 마우스 동작(휠 확대, 끌어서 확대 상자, 두 번 클릭 등)은 그대로다.

## Image Analysis — 나노입자 세기 (Threshold → Binary → Analyze Particles)
**한 번에: Analyze 패널 맨 위 [Analyze particles (auto)]** — 이미지를 열고 이 단추만 누르면 아래 순서를 권장값으로 해서 크기 분포(Size distribution)까지 보여 준다. 원본 이미지는 그대로 두고 사본(… particles)에서 한다.
흐림(입자 크기에 맞춰 σ 를 정함 — 고배율이면 지지막 결까지 지움) → 문턱 Default(밝은 바탕·어두운 입자인지 자동 판단) → Fill Holes → Watershed → **겹치거나 붙은 같은 크기 입자를 크기·중심(LoG)으로 나눔** → 축척 막대·글자 자동 제외(가장자리 근처 막대를 찾아 그 둘레 덩어리를 뺌, 눈금이 없으면 막대 글자를 읽어 정함) → Size ≥ 성분 넓이 중앙값의 ¼, Circularity 0.5–1, Exclude on edges, 세기는 원본에서. 영역 ROI 를 그려 두면 그 안만.
나눈 입자는 경계선(1 px)과 겹친 부분만큼 지름이 조금(이 예에서 ~4 %) 작게 나온다 — 정확한 평균 지름이 중요하면 Circularity 하한을 0.85 쯤으로 올려 홑입자 위주로 보자. 결과가 이상하면 아래 순서를 직접 맞춘다(고급).

TEM 명시야처럼 **밝은 바탕에 어두운 입자**, 입자끼리 붙어 있는 이미지의 순서. (예: 0.55 nm/px, 지름 ≈ 23 nm 입자 400 여 개)
1. **눈금 확인** — 왼쪽 목록에 nm/px 가 보이면 됨(GMS·FEI·Zeiss 태그 자동). 없으면 Line 도구로 축척 막대 위에 선 → Adjust ▸ Set Scale.
2. **잡음 줄이기** — Process ▸ Gaussian Blur σ 1–2 px. 이걸 빼면 잡음 점 하나하나가 입자로 잡혀 수만 개가 된다.
3. **문턱** — Threshold 패널: Method Default(또는 Otsu), **Dark background 끔**(어두운 입자). 빨간 칠이 입자 위에만 있고, 'selected' 가 절반을 넘으면 거꾸로 고른 것. → **Convert to Mask**.
4. **붙은 입자 나누기** — Binary ▸ Fill Holes(입자 안 밝은 점 메우기) → Binary ▸ **Watershed**.
5. **축척 막대·글자 빼기** — 그 부분을 피해 사각형(또는 다각형) ROI 를 그린다. ROI 가 있으면 그 안만 센다.
6. **Analyze Particles** — Size 최솟값 = 입자 넓이의 1/4 쯤(예: 100 nm²), Circularity 0.5–1(겹친 덩어리·가장자리 선 제외), Exclude on edges 켬.
6b. Watershed 로 안 나뉜 덩어리가 남으면 Binary ▸ **Split by size** (같은 크기 입자 가정).
7. 결과 카드의 ECD mean ± SD·D50, Size distribution. 여러 층으로 겹친 덩어리는 Watershed 로도 못 나눠 Circularity 에서 빠진다 — 개수는 '잴 수 있었던 입자 수'로 보고하고, 크기 분포는 그대로 쓸 수 있다.
- **Max count**(기본 2000): 조건에 맞는 입자가 이보다 많으면 측정하지 않고 1–2 초 만에 멈춰 원인(극성 반대·잡음)을 알려 준다 — 설정을 잘못해 페이지가 멈추던 것을 막는 장치. 정말 많은 이미지면 값을 올린다.

## Image Analysis — 접촉각 · 펜던트 드랍 (Analyze ▸ Drop Shape)
ImageJ 의 DropSnake·LB-ADSA·Pendent Drop 플러그인 대신 쓰는 기능. 오른쪽 **Analyze** 패널 맨 아래 **Drop Shape** 칸(패널 머리의 **Drop Shape ↓** 단추로 바로 감).

**접촉각 (Contact angle)**
1. 방울 옆모습 이미지를 연다(8·16-bit, RGB 는 밝기로). 방울은 바탕보다 어둡든 밝든 된다.
2. 사각형 ROI 로 방울과 그 아래 기판 윗면을 함께 감싼다(없으면 이미지 전체). 주사기 바늘이 방울에 꽂혀 있으면 영역 위 테두리가 바늘을 가로지르게 — 바늘 끝보다 위 윤곽은 자동으로 뺀다.
3. 기준선은 자동(기판 윗면). 거울 같은 기판(방울 반사상이 보임)이나 기판이 잘 안 보이면 Line 도구로 기판 윗면을 따라 선을 긋고 **Use line ROI**.
4. 방법을 고르고 **Measure θ**. 표의 θ 는 액체 쪽에서 잰 각. 기준은 **Young–Laplace**(중력 포함) — 원(구면 모자)은 작은 방울(Bond 수 ≈ 0)에서만 맞고, 접선법은 접촉점 둘레만 본다(왼·오른 각이 따로 나와 고정·이력 비대칭을 볼 때 좋음).
5. 이미지 눈금(Set Scale)이 있으면 부피·밑면 지름·높이도.

**펜던트 드랍 (표면장력)**
1. 바늘 아래 매달린 방울 이미지. 사각형 ROI 의 **위 테두리가 바늘을 가로지르게** 잡는다(바늘이 보여야 눈금을 정한다).
2. **Needle Ø** = 바늘 바깥 지름(mm, 예: 22 G ≈ 0.72 mm — 쓰는 바늘을 캘리퍼로 재는 것이 가장 정확). ρ drop·ρ outside(기본 물 998.2·공기 1.204 kg/m³), g.
3. **Measure γ** → γ(mN/m), Bond 수, Worthington 수, 부피·겉넓이·apex 곡률 반지름, 기울기.
4. Worthington 수(Wo)가 0.5 보다 작으면 경고 — 방울이 작아 중력 변형이 약하면 γ 가 흔들린다. 떨어지기 직전 크기(Wo → 1)가 가장 정밀(Berry et al. 2015).
5. γ 옆 ± 는 **맞춤 통계만**이다. 바늘 지름 1 % 오차는 γ 2 % 오차가 된다 — 같은 방울 여러 장(스택이면 Frames: All)의 흩어짐을 함께 보고하자.

**검증**: 정답을 아는 합성 방울(γ 오차 중앙 0.06 %, θ 오차 ≤ 0.85°)과 OpenDrop 공개 예제(물 γ: OpenDrop 과 −1.2 %, 5 장 평균 73.1 mN/m ↔ 물 72.0–72.8 mN/m; 접촉각 접선 118.8°/123.8° ↔ 120.0°/124.2°). 자세한 것은 modules/image/SPEC.md §3h.

## 이미지 뷰어

- **대비**: 기본은 0.35–99.65 백분위 자동 대비. `전체 범위` 로 원본 min–max 복귀.
- **확대**: 슬라이더 또는 마우스 휠. `이동` 도구에서 드래그로 팬.
  축소 시에는 부드럽게, 확대 시에는 픽셀 그대로 렌더한다.
- **스케일바**: 파일에 기록된 픽셀 크기(`BinaryResult.PixelSize`, Bruker 는 `TRTSEMData/DX`)를
  그대로 쓴다. 배율이 아니라 픽셀 크기 기준이므로 별도 보정이 필요 없다.
- **거리·프로파일**: 드래그하면 길이(nm)와 라인 프로파일이 함께 나온다. CSV 내보내기 가능.
- **ROI 통계**: 사각 영역의 평균·표준편차·최소·최대·SNR.

### 프레임 스택

SI 취득에서 HAADF 는 스캔 프레임마다 한 장씩 쌓인다(예: 512×512×106, 드웰 5 µs).
한 장만 보면 사실상 잡음이므로 **전체 합**이 기본이고, `첫 장` 으로 전환할 수 있다.
메모리를 위해 프레임은 통째로 읽지 않고 잘라서 누적한다.

### ROI 스펙트럼

`ROI 통계` 도구로 영역을 그린 뒤 **이 영역의 EDS 스펙트럼**을 누르면 그 픽셀들의
X선만 모은 스펙트럼이 만들어져 스펙트럼 탭에 추가된다. `밝기 문턱 적용`을 켜면
표시 **최소** 슬라이더 값 아래(지지막·구멍)를 빼고 입자 픽셀만 모은다.

시야 전체 합에는 지지막과 그리드가 섞여 있으므로, 정량은 가능하면 ROI로 좁혀서 한다.
실제 파일에서 확인한 효과(NaLuF4:Tm / Lacey C / Ni grid):

| 영역 | 픽셀 | C / Lu 세기비 |
|---|---|---|
| 시야 전체 | 262,144 | 8.71 |
| 밝기 상위 40% | 104,860 | 4.55 |
| 밝기 상위 25% | 65,537 | **3.16** |
| 하위 40%(배경) | 104,858 | Lu·Tm·Na = 0, F ≈ 0 |

배경 영역에서 입자 원소가 정확히 0으로 나오는 것이 공간 분리가 제대로 되고 있다는 증거다.

### 원소맵

SI `.emd` 에는 Velox 가 계산해 둔 원소맵이 함께 저장된다. 검출기 이름만으로는 어느
원소인지 알 수 없어(`SuperXG2`), `Displays/ImageDisplay` 를 따라가 원소 이름을 붙인다.
이미지 선택 목록에 `F map`, `Lu map` 처럼 표시된다.

> 이 맵들은 Velox 의 **창 적분(Integration)** 결과다. 서로 겹치는 L선(Tm/Yb/Lu 등)을
> 분리하지 못하므로, 조성 판단은 스펙트럼 탭의 동시 적합 결과를 기준으로 할 것.

## 원소 맵 겹쳐보기

원소마다 색을 골라 기준 상(HAADF) 위에 가산으로 겹친다. 층은 두 곳에서 온다.

* **Velox 맵** — 파일에 저장된 것. 이름 옆에 `(Velox)` 로 표시된다.
* **계산 맵** — 스펙트럼 스트림을 디코드해 앱이 직접 만든 것. 비닝을 바꿀 수 있다.

색 사각형을 누르면 12색 팔레트가 열린다. 각 층의 슬라이더는 섞는 세기이고,
`평활` 은 표시에만 적용된다(계산값은 그대로).

처음 열었을 때 어느 층이 켜져 있는지는 **파일에 저장된 Velox의 겹쳐보기 상태**를
그대로 따른다(`SharedProperties/DisplayGroupItem` 의 blendFactor). 저장된 상태가
없으면 앞의 두 층만 켠다 — 전부 켜면 가산 합성이 흰색으로 포화된다.

### 스트림에서 맵 계산

**동시 적합**과 **창 적분** 두 방식이 있다.

* **동시 적합(기본)** — 검출된 원소 전부와 배경을 화소마다 동시에 푼다.
  겹친 선이 제대로 나뉜다. 같은 파일·같은 비닝에서 입자/배경 대비를 재면:

  | 원소 | 창 적분 | 동시 적합 |
  |---|---|---|
  | Lu L | 3.2 | **25.2** |
  | Tm L | 2.4 | **10.9** |
  | F K | 32.3 | 38.8 |
  | Na K | 23.7 | 26.8 |
  | C·Ni·Cu·Zr | 거의 그대로 (원래 겹치지 않는다) |

  Lu Lα(7.655)와 Tm Lα(7.180)는 Ni Kα(7.478)의 양 어깨에 묻혀 있어 배경창을
  어디에 두든 제대로 뺄 수 없다. 어느 원소를 화면에 띄우든 **적합에는 항상 전부**
  들어간다 — 그래야 세기 배분이 맞는다.

* **창 적분** — 주선 창에서 세고 양옆 창으로 배경을 뺀다. Velox·Bruker 와 같은 방식이라
  비교용으로 남겨 두었다.

`스펙트럼 스트림 디코드`를 한 번 누르면 픽셀별 X선을 읽어 들인다. 이후 맵과 ROI
스펙트럼은 즉시 계산된다. 전체 이벤트의 97~98%가 제로 스트로브라 버리고 나면
실제 X선은 20만~60만 개뿐이고, 희소 목록으로 1~4 MB 밖에 되지 않는다.

**비닝을 반드시 의식할 것.** 픽셀당 유효 카운트가 1 안팎이라 원본 화소 맵은 잡음이다.
8×8 비닝이 기본이고, 화소 크기는 상단 타일에 표시된다.

## EDS 스펙트럼

### 에너지 보정

```
E [keV] = (OffsetEnergy + Dispersion × channel) / 1000
```

값은 파일의 검출기 메타데이터에서 읽는다. Bruker 는 `CalibAbs` / `CalibLin`(keV 단위)이
같은 역할을 한다.

### 유효 구간 하한

검출기 하한 아래에는 X선이 아니라 **제로 스트로브**(펄스 프로세서의 기준선 복원 이벤트)와
전자 노이즈가 들어 있다. 이것을 배경 추정이나 피크 탐색에 넣으면 결과가 통째로 어긋난다.

- Velox: `BeginEnergy` 를 그대로 쓴다(보통 120 eV).
- Bruker: 해당 항목이 없으므로 파일이 준 분해능 모형에서 σ(0)=√SigmaAbs 를 구해
  **5σ** 까지를 잘라낸다. 실제 파일에서 제로 피크가 끝나는 채널과 일치한다.

제외된 카운트의 양과 비율은 스펙트럼 탭 상단에 항상 표시된다. **이 비율이 클 수 있다** —
SI 취득에서는 전체 이벤트의 98%가 제로 스트로브인 경우가 관측된다. 그런 파일에서
"총 카운트"는 통계의 근거가 되지 못하며, 화면에 표시되는 **유효 카운트**만 의미가 있다.

### 합산 스펙트럼

Super-X 는 검출기가 넷이고 Velox 는 세그먼트별 스펙트럼을 따로 저장한다.
세그먼트 하나를 열면 카운트의 3/4을 버리게 되므로 합을 기본으로 연다.

- 낱장 `.emd`: 파일이 `Summed` 항목을 알려 준다.
- SI `.emd`: 합이 저장되지 않으므로 앱이 네 세그먼트를 더해 만든다.
- 계수율(ICR/OCR)과 live time 도 합 기준으로 표시한다. 세그먼트마다 값이 다르므로
  한 세그먼트의 값을 합산 스펙트럼 옆에 띄우면 4배 어긋난다.

### 검출기 분해능 — 제로 스트로브에서 직접 잰다

```
FWHM(E) = 2.355 × √(σ₀² + F·ε·E)      F = 0.12 (Fano), ε = 3.86 eV
```

σ₀ 는 **버리는 제로 스트로브 봉우리에서 직접 잰다.** 그 봉우리가 0 eV 짜리
전자 노이즈 분포 그 자체이기 때문이다. 채널 폭이 만드는 겉보기 넓어짐은 빼 준다.

Velox 의 `ElectronicsNoise`(27.69) 를 σ 로 쓰면 FWHM(Mn Kα) = 139.3 eV 가 나오는데,
같은 파일의 제로 피크를 재면 σ₀ = 16.8 eV, 즉 **129.2 eV** 다. 27.69 를 FWHM 으로
봐도(11.76) 맞지 않는다. 실측을 쓴다.

Bruker 는 `SigmaAbs` / `SigmaLin` 으로 분해능 모형을 **직접** 담고 있으므로 그것을
그대로 쓴다. 교차 확인: 헤더의 σ₀ = 20.97 eV, 같은 파일 제로 피크 실측 21.7 eV
(3% 이내). 그리고 Bruker 헤더의 128.6 eV 와 Velox 실측 129.2 eV 가 서로 맞는다 —
Velox 메타데이터만 어긋나 있었다.

스펙트럼 탭 상단에 어느 쪽을 썼는지 표시된다.

### 피크 검출

- 배경: **SNIP** (LLS 변환 후 반복 클리핑). 클리핑 폭을 에너지별 FWHM 에 맞춰 조절하므로
  강한 선 사이의 넓은 평탄부를 파먹지 않는다. 클리핑 창은 유효 구간(하한 위)에서만
  움직인다 — 창이 0으로 눌린 제로 스트로브 구간까지 내려가면 배경이 그쪽으로 무너진다.
- 피크: FWHM 폭으로 묶어 **적분 면적**으로 세고, 포아송 유의도로 판정한다.
  단일 채널 높이로 판정하면 강한 선 하나가 여러 개로 쪼개진다.
- 허용오차: 0.6 × FWHM(E), 최소 50 eV.

### 자동 원소 식별

**동시 적합**이다. 후보 원소들의 계열 모형을 한꺼번에 세우고 비음수 최소제곱(NNLS)으로
세기를 나눈다. 겹친 원소의 세기 배분이 하나의 문제로 풀리므로, 순차 스트리핑에서
생기던 "먼저 뺀 원소가 나중 원소를 지우는" 문제가 없다.

판정 기준:

- **검출한계 = 3σ.** σ 는 (AᵀWA)⁻¹ 에서 나오므로 겹친 원소는 자동으로 σ 가 커진다.
  Gd Lβ1(6.708)과 Ho Lα(6.720)처럼 12 eV 쌍은 여기서 스스로 벌어진다.
- **후진 제거.** 검출한계 미만인 후보를 약한 것부터 빼 보고, χ² 가 유의하게 나빠지면
  되돌린다. "개별로는 한계 미만"과 "모형에 불필요"는 다른 질문이기 때문이다.
  빼면 스펙트럼을 설명할 수 없는 원소는 `겹침 필수` 로 따로 표시한다.
- **계열 관문.** K 는 제한 없음, L 은 Z ≥ 30, M 은 Z ≥ 57, 그리고 K 가 아닌 계열은
  주선이 0.80 keV 이상일 것. 그 아래에서는 형광수율이 사실상 0이라 실재하는 봉우리를
  만들지 못하고, 대신 모형 오차를 흡수하는 가짜 성분이 된다.

**저에너지 응답의 비대칭.** 낮은 에너지의 선은 가우시안이 아니다. 불완전 전하수집
때문에 저에너지 쪽으로 지수 꼬리가 붙고, 그만큼 면적이 중심에서 빠져나간다.
입자만 고른 ROI 스펙트럼(전 프레임, 두 독립 취득)에서 잰 값:

| 선 | E (eV) | 꼬리 비율 fT |
|---|---|---|
| C Kα | 277 | > 0.85 |
| O Kα | 525 | 0.54 / 0.60 |
| F Kα | 677 | 0.27 / 0.25 |
| Na Kα | 1041 | 0.00 |

감쇠 길이는 0.90 σ. 이 모형을 넣으면 140–1250 eV 구간의 χ²ᵣ 가 **31.6 → 2.8**
(다른 파일은 106 → 6.1) 로 떨어진다. 따로 잰 중심 이동(C −12, O −8.5, F −3.4,
Na 0 eV)과도 방향·크기가 맞는다.

모양은 위 실측에서 고정하고 크기만 스펙트럼마다 τ 로 잰다.

```
fT(E) = min(0.85, τ × 0.27 × (677/E)^2.93)
프로파일 = 가우시안 + fT × (꼬리 − 가우시안)
```

프로파일이 fT 에 대해 정확히 선형이라 τ 도 잔차에서 한 번의 최소제곱으로 구해진다.
꼬리가 없는 자료에서는 τ 가 0 근처로 떨어져 결과가 이전과 같아진다.

**M 계열 결합.** 200 kV 에서 란탄족·중원소는 L선과 M선이 함께 나온다. M선을 모형에서
빼면 그 자리(1.4–1.8 keV)를 Al 같은 이웃 원소가 차지한다. 그래서 M 계열을 독립 성분이
아니라 **묶인 성분**으로 넣는다:

```
prof = profL + ρ · profM
```

ρ 는 스펙트럼 전체에서 공유하는 값 하나이고, L선만 넣은 1차 적합의 잔차로부터 직접
잰다. χ² 가 3σ 이상 좋아질 때만 받아들이므로, M선이 실제로 없는 시료에서는 ρ 가 0으로
떨어지고 결과가 단일 계열과 같아진다.

ρ 와 τ 는 서로 영향을 준다 — 꼬리를 넣어야 그 위의 원소가 검출 등급에 올라오고,
그래야 그 원소의 M 계열이 ρ 추정에 들어간다. 그래서 증분이 유의하지 않을 때까지
(보통 2회, 최대 3회) 되풀이한다.

> **자동 식별은 후보 제시이지 최종 판정이 아니다.**
> 특히 란탄족은 L·M선이 서로 심하게 겹치므로 **간섭 검사** 탭을 함께 볼 것.

### 정량

Cliff-Lorimer 비 방법이다.

```
C_A / C_B = k_AB × (I_A / I_B)
```

k-factor 는 **추정하지 않는다.** 조성을 아는 시료에서 역산해 브라우저에 저장하고,
같은 조건의 다른 스펙트럼에 적용한다. k 가 없는 원소가 있으면 그 사실을 표에 표시한다.

불확도는 세기에서 전파한다(k 자체의 불확도는 포함되지 않는다).

같은 물질을 다른 배율로 독립 취득한 두 파일로 교차검증하면, 한쪽에서 잰 k 로 다른 쪽을
정량했을 때 조성이 되돌아와야 한다.

### k 세트

k 는 **가속전압·검출기·기하가 같을 때만** 옮겨진다. 그래서 잴 때의 조건을 함께 저장한다.

```
{ 이름, 만든날짜, 조건{kV, 검출기, FWHM(MnKα), 분산}, 기준원소, 가정조성, k{...}, 출처파일 }
```

* 활성 세트 하나가 정량에 쓰이고, 정량 카드 머리에 이름과 조건이 표시된다
* **활성 세트의 조건이 지금 스펙트럼과 다르면 경고가 뜬다** — 가속전압이 다르거나
  분해능이 5% 넘게 차이나면. 이걸 놓치면 조성이 조용히 틀린다
* `k 세트…` 에서 고르기·이름 바꾸기·지우기, JSON 으로 내보내고 들여오기
* 새 표준을 재면 앞의 세트를 덮어쓰지 않고 새 세트로 쌓인다

### 화학량론으로 k 를 잴 때의 함정

조성을 안다고 해서 그 원소를 모두 제약으로 쓸 수 있는 것은 아니다. **그 원소가 실제로
분석 영역 안에 그 비율로 들어 있어야** 한다.

실제 사례(NaLnF4): Na 를 화학량론 제약(Na:Ln = 1:1)에 넣었더니 두 독립 취득의
교차검증이 **33% 어긋났다.** HAADF 밝기 십분위별로 스펙트럼을 뜯어 보니 Na 만 분포가
달랐다 — Lu·Tm·F 는 밝은 상위 30% 에 67–85% 가 몰려 있는데 Na 는 38–55% 뿐이고
나머지는 중간 밝기 구간에 있었다. Na 가 입자 밖에도 상당량 있다는 뜻이다.

Na 를 빼고 **F:(Lu+Tm) = 4:1** 로만 재니 교차검증이 1–4% 로 맞았다.

> 화학량론 제약은 **공간 분포가 함께 움직이는 원소들 사이에서만** 쓸 것.
> 의심스러우면 ROI 를 바꿔 가며 그 비가 유지되는지 먼저 확인한다.

## 흡수 보정 (박막 Cliff-Lorimer 확장)

Cliff-Lorimer 는 시료가 충분히 얇아 X선이 나오는 길에 흡수되지 않는다고 가정한다.
실제로는 **저에너지 선이 시료 안에서 먹힌다** — 그리고 그 양은 두께에 따라 변한다.

```
I_meas = I_gen · [1 − exp(−χ·ρt)] / (χ·ρt) ,   χ = (μ/ρ)_시료 · csc(α)
C_A/C_B = k_AB · (I_A/I_B) · f_B/f_A
```

α = take-off 각(파일에서 읽음), ρt = 질량두께 [g/cm²] = 두께 × 밀도.
(μ/ρ)_시료 는 조성에 의존하고 조성은 다시 보정에 의존하므로 **반복해서 푼다**(보통 4~7회).

> **입체각 Ω 는 이 식에 들어가지 않는다.** Ω 는 계수율·검출한계와 ζ-factor 법에 필요한 값이지
> 흡수 보정의 입력이 아니다. 앱은 Ω = 0.9 sr(시스템 총합 가정)을 장비 레지스트리에 기록만 해 둔다.

### 시료 형상 — 나노입자에 박막식을 쓰면 3~4배 과대평가한다

표준 Cliff-Lorimer 흡수식은 **평평한 박막**을 가정한다. 나노입자는 두 가지가 다르다.

1. **구는 등방이다.** 균일하게 생성된 X선이 표면까지 가는 거리 L 의 분포가 방향에 무관하므로
   **take-off 각이 결과에 들어가지 않는다**(⟨L⟩ = 3R/4). 반면 박막식은 csc(22°) = 2.67 을 곱한다.
   같은 공칭 두께에서 박막식은 흡수를 **3~4배 과대평가**한다.
2. **조밀 단층에서는 이웃을 지난다.** 낮은 각으로 빠져나가며 옆 입자들을 통과하므로 이 항은
   다시 take-off 각에 의존한다.

앱은 세 가지 형상을 제공한다.

| 형상 | 입력 | take-off 각 | 언제 |
|---|---|---|---|
| **고립 구형 입자** | 지름 d | **불필요** (등방) | 성긴 입자 · 하한 추정 |
| **조밀 단층** | 지름 d, 피복률 φ | 필요 | 입자가 서로 닿아 있을 때 |
| **평평한 박막** | 두께 t | 필요 | 연속막 · 상한 추정 |

단층 모델은 `f_sphere(μR) · exp(−μ·φ·(d/2)·cot α)` 의 **1차 근사**다 — 피복이 통계적으로 균일하다는
가정이므로 정확한 값이 아니라 규모 추정용으로 본다. 실제 값은 고립 구와 박막 사이에 있다.

### 크기와 밀도에는 기본값이 없다 — 그리고 그것이 의도다

크기는 데이터마다 완전히 다르다. 어떤 예제에서 얻은 수를 기본값으로 박아 두면, 다른 데이터에서
**앱이 조용히 틀린 조성을 낸다.** 그래서 이 두 칸은 비어 있고, 채우는 방법을 두 가지로 나눴다.

- **크기** — `[HAADF 에서 재기]` 버튼이 **지금 열려 있는 이미지**에서 직접 잰다.
  Otsu 이진화 → 정확 유클리드 거리변환 → 국소 최대점. 입자마다 EDT 최대점이 하나 생기고
  그 값이 반지름이므로 서로 닿아 있어도 분할 없이 크기를 얻는다. 지름 중앙값·10~90% 폭·피복률을
  함께 보여 주므로 분포가 넓으면 그 자리에서 보인다.
- **밀도** — 이미지로는 알 수 없는 **물질 속성**이다. 결정상과 조성을 보고 넣어야 한다.
  앱이 추측하지 않는다.

### 남은 불확실성은 숨기지 말고 재라 — 크기 민감도

크기를 하나로 정해 놓고 끝내는 대신, 앱은 그 값을 **×0.5 / ×2 로 흔들어** 조성이 얼마나
움직이는지 함께 보여 준다. 판단해야 할 질문은 "크기가 정확한가"가 아니라
**"이 불확실성이 내 결론을 바꾸는가"** 이기 때문이다. 실제 예:

| 지름 | 절반~두 배로 흔들 때 조성 변화 | 해석 |
|---|---|---|
| 13.7 nm | F 0.23 at%p | 크기를 정확히 몰라도 결론이 안 바뀐다 |
| 94 nm | F 1.33 at%p | 크기 추정이 결론을 좌우한다 — 실측값을 넣어야 한다 |

### 규모 감각 — 형상별 F/Ln 편향

아래는 무거운 기지(Ln 계열, ρ ≈ 6.5, take-off 22°)에서 **F Kα(677 eV)** 가 받는 편향의 예다.
물질이 다르면 (μ/ρ)와 밀도가 달라져 값도 달라지므로, **표를 그대로 쓰지 말고 앱이 계산하게 하라.**

| 지름·두께 | 고립 구 | 조밀 단층 (φ 59%) | 평평한 박막 |
|---|---|---|---|
| 5 nm | 0.46% | 1.36% | 1.64% |
| 15 nm | 1.39% | 4.13% | 4.97% |
| 30 nm | 2.78% | 8.42% | 10.08% |
| 100 nm | 9.41% | 30.78% | 35.98% |

무거운 원소(L선, 7~8 keV)는 거의 흡수되지 않고 **저에너지 선만 먹히므로**, 보정하지 않으면
정규화가 그 손실을 무거운 쪽으로 몰아준다. **수 nm 입자에서는 무시할 만하고, 100 nm 급
응집체에서는 30% 를 넘는다** — 같은 시료라도 어느 영역을 재느냐가 지배적이다.

### k-factor 와의 짝 — 이중 보정 함정

**보정 없이 잰 k 에는 잴 당시 두께의 흡수가 이미 배어 있다.** 그런 k 를 쓰면서 여기서 또
보정하면 같은 효과를 두 번 뺀다. 앱은 k 세트마다 보정 여부를 기록하고 어긋나면 경고한다.

| k 세트 배지 | 뜻 |
|---|---|
| `흡수 보정 k · 30 nm에서` | 흡수를 보정하고 쟀다 — **두께에 묶이지 않는 참 k**. 다른 두께에도 옮길 수 있다 |
| `실효 k · 흡수 미보정` | 잴 당시 두께에서만 유효. 다른 두께로 옮기면 조용히 틀린다 |

합성 데이터로 확인한 왕복 시험 (30 nm 표준 → 100 nm 미지, 정답 Lu 12.94):

| 방식 | 표준(30 nm) | 미지(100 nm) |
|---|---|---|
| 미보정 k · 미보정 정량 | 12.94 ✓ | **15.31 (+18%)** |
| 보정 k · 보정 정량 | 12.94 ✓ | **12.95 ✓** |

참 k 는 **k_true = k_meas / (f_ref/f_i)** 만큼 다르다. 30 nm 에서 F 기준이면 f_F/f_Lu = 0.908,
즉 **미보정 k 가 참값보다 9% 작다**.

> 배포된 `kfactors_NaLnF4.json` 은 **흡수 보정 없이** 잰 것이다(`abs.on = false`).
> 그 k 를 뽑은 SI 파일에서 `[HAADF 에서 재기]` 로 재면 지름 중앙값 **13.7 nm**(10~90% 10.0~18.0,
> 피복률 35%)이 나온다. 이 크기에서 흡수 편향은 **1% 안쪽**이라 참 k 와 거의 차이가 없다.
> 다만 이것은 **그 파일의 이야기**이고, 큰 입자·두꺼운 영역을 잰 데이터에는 그대로 적용되지 않는다.
> 새 데이터를 정량할 때는 그 데이터에서 다시 재라.

### 믿을 수 없는 경우

- **흡수단에 붙은 선.** 방출선이 어떤 흡수체의 흡수단 1.5% 안에 있으면 μ/ρ 가 물리적으로
  불연속이라 표값이 어느 쪽인지 정할 수 없다. 앱이 그 짝을 찾아 경고한다.
- **μ/ρ 자체의 불확도.** 독립 컴파일(Elam vs Chantler) 사이에 **2~10%** 차이가 있고 저에너지에서
  더 크다. 보정이 10%면 그 중 약 1%가 여기서 온다 — 보정을 안 하는 것보다는 훨씬 낫지만,
  보정값을 소수점 아래까지 믿지는 말 것.
- **ρt 를 모를 때.** 이것이 유일한 미지수이고 파일에 없다. 틀린 두께를 넣으면 조용히 틀린 조성이
  나온다. 위 표의 두께 의존성이 곧 두께 오차의 민감도다.

μ/ρ 데이터: **Elam, Ravel & Sieber (2002)** — 방출선 에너지와 같은 출처. 흡수단을 양옆에서
감싸는 로그-로그 격자로 표집한 뒤, 보간 오차가 0.5% 안에 들도록 솎아냈다(중앙값 0.07%, 99% 0.49%).

## 격자 · FFT (HRTEM d-spacing)

### 측정 사슬 — 각 단계가 어디에 오차를 넣는가

```
실공간 화소 px [nm/px]      ← 파일 메타데이터. 현미경 배율 교정에 의존한다(지배적 계통오차)
  → 창함수                  ← 가장자리 불연속이 만드는 십자 줄무늬 제거
  → 2D FFT → |F|²
  → 역공간 눈금 Δg = 1/(N·px)
  → 스폿 위치 부화소 정밀화   ← 파워 가중 중심 반복(대칭 스폿에서 편향 없음)
  → Friedel 짝(±g) 평균      ← 중심 오프셋이 상쇄된다
  → |g| → d = 1/|g|
```

**각도와 d 비는 화소 크기에 전혀 의존하지 않는다.** 배율 교정이 틀려도 이 둘은 맞으므로,
정대(zone axis) 판정에는 d 절대값보다 이쪽이 믿을 만하다.

### 합성 격자로 검증한 정확도

정답을 아는 격자를 만들어 재보았다. 격자 눈금에 **일부러 안 맞는** d(30.5 bin)를 넣고,
클릭 위치도 **2 px 어긋나게** 시작했다.

| 시험 | 결과 |
|---|---|
| 깨끗한 격자 15가지(3각도 × 5 d) | 최대 오차 **0.000%** |
| 잡음(신호 대비 12배)까지 | 오차 **0.018%** |
| 창함수 Hann / Hamming / 없음 | 0.002% / 0.001% / 0.046% |
| 각도의 화소 크기 의존성 | 없음(px 2배·½배에서 동일) |
| 두 격자 사잇각(참값 60°) | **60.00°** |
| 마스크 역FFT ↔ 원래 격자 상관 | **0.98**, 허수부 2e-15 |

> 이 수치는 **알고리즘의 정확도**이지 측정의 정확도가 아니다. 실제 한계는 아래 계통오차다.

### 실제 데이터에서의 자기검증

측정이 옳은지 확인하는 방법을 두 가지 넣었다. 둘 다 **정답을 몰라도** 쓸 수 있다.

**1. 고차 반사 일관성** — 같은 방향에 |g| 가 정수배로 놓인 스폿은 같은 격자면의 1차·2차·… 반사다.
정수비에서 벗어나면 측정이나 교정에 문제가 있다는 신호다. 실제 HRTEM 에서:

```
스폿 #1, #2 = 1차, 2차 → 1차 2.9650 Å (여러 차수 동시 적합)
정수비 최대 편차 0.08%  → 일관
```

여러 차수를 원점 지나는 직선으로 함께 적합하면 g₁ 이 더 정확해진다.

**2. 축 정렬 경고** — 가로·세로 축에 딱 붙은 스폿은 카메라 판독 줄무늬·스캔 잡음·창 누출인
경우가 많다. 실제 격자가 우연히 축에 정렬될 수도 있으므로 **경고이지 판정이 아니다.**

**3. 역FFT 허수부** — Friedel 대칭 마스크의 역변환은 실수여야 한다. 허수부 비율을 항상 표시한다
(정상이면 10⁻¹³% 수준). 값이 크면 마스크가 대칭이 아니라는 뜻이다.

### 스폿 자동 찾기 — 왜 '가장 밝은 점'이 아닌가

파워 스펙트럼은 |g| 가 작을수록 압도적으로 밝다(비정질 헤일로·저주파 구조·CTF 포락선).
그냥 최대값을 고르면 늘 중심 근처만 잡힌다. 그래서 **반지름마다 중앙값을 구해 그것으로 나눈 뒤**
찾는다 — 각 반지름에서 "주변보다 몇 배 튀는가"로 비교한다. 표의 `배경대비` 열이 그 값이고,
평균이 아니라 중앙값을 쓰는 이유는 평균이 스폿 자신에게 끌려가기 때문이다.

### 지배적 오차는 배율 교정이다

알고리즘 오차가 0.00x% 여도 **현미경 배율 교정이 1~2% 틀리면 d 도 그만큼 틀린다.**
교정하지 않았다면 그렇게 보고하는 것이 정직하다. 같은 배율로 표준 격자면을 찍어 두었다면
**배율 교정** 카드에서 보정할 수 있다(Au(111) 2.3550 Å, Si(111) 3.1355 Å 등이 목록에 있다).

교정은 **그 배율에서만** 유효하다. 배율을 바꾸면 다시 해야 한다.

### 실용 한계

| 한계 | 값 | 뜻 |
|---|---|---|
| Nyquist | 2 px | 이보다 촘촘한 줄무늬는 원리적으로 못 잰다 |
| 실용 하한 | 4 px/줄 | 이 아래는 부화소 정밀화가 급격히 나빠진다 |
| 역공간 눈금 | Δg = 1/(N·px) | N 을 키우면 촘촘해지지만 그만큼 넓은 영역을 평균한다 |

FFT 영역을 키우면 눈금이 촘촘해지는 대신 **여러 결정립·변형이 섞인다.** 단결정 영역을 골라
가능한 큰 N 을 쓰는 것이 정석이다.

### 내보내기

- **PNG** — 실공간(FFT 영역 표시) · FFT(스폿과 d 라벨) · 역FFT 를 한 장에 합치고,
  화소 크기·교정 여부·창함수·Δg 를 머리글에 적는다. 근거가 그림 안에 함께 있어야 한다.
- **CSV** — d[Å], d[nm], |g|, 각도, |g|[px], Friedel 여부, 배경대비, 그리고 **화소 크기·교정 계수·
  N·창함수·ROI 위치·원본 파일명**까지. 스폿 쌍의 사잇각과 d 비도 함께.

## 간섭 검사

맨 위에 **원소별 추천 라인**이 나온다. 전체 라인쌍 겹침 목록은 그 아래 '전체 겹침 목록'을 펼쳐서 본다.

### 원소별 추천 라인

원소마다 intensity 는 크고 interference 는 작은 분석 라인(= 적분 window)을 하나 고르고, alternative도 함께 보인다.

- **window**: 라인 에너지 ± 0.6·FWHM(E) (선의 84 %).
  - 같은 원소의 선이 FWHM 의 절반 안쪽으로 붙어 있으면 한 window 로 묶는다. 예: Lα1,2, Kα1,2.
- **판정량 — 예상 상대오차**: window 안의 원소 신호 S, 다른 원소 선 B_int, 배경 B_bg 로 계산한다.
  - err = √(S + B_int + B_bg + Σ(δ·B_f)² + (0.03·B_bg)²) / S
  - 계수 통계, 겹친 선을 빼낼 때의 line ratio 불확도 δ(K 0.03, L 0.05, M 0.15), 배경 차감 오차를 합친 값이다.
  - 겹침이 없으면 √S/S 이므로 intensity 가 클수록 작아진다. 겹치면 B 가 커지면서 오차도 커진다. 이 값이 가장 작은 라인을 추천한다.
- **purity** = S / (S + B_int)
  - ≥ 90 %: clean.
  - 60–90 %: overlap 보정. interferer 를 그 원소의 다른 선으로 재서 빼야 한다.
  - < 60 %: deconvolution(MLLS) 필요.
  - 예상 상대오차가 50 %를 넘으면 '신호 부족'으로 표시한다.
- **intensity 출처**
  - **스펙트럼 파일이 열려 있으면 실측값**을 쓴다. 선택 원소의 계열별 선 모양을 배경 뺀 스펙트럼에 NNLS 로 맞춘 counts 다.
    - 선 모양은 스펙트럼 탭 자동 식별과 같다: Gaussian + 저에너지 불완전 전하수집 꼬리. 꼬리 크기 τ 는 residual에서 잰다.
    - SNIP 은 연속선을 낮게 잡는다(실측 파일에서 9–11 keV 는 0, 6–7 keV 는 필요량의 2 %). 이 부족분은 넓은 hat 기저(마디 간격 ≥ 4·FWHM)로 함께 맞춘다.
    - 쓰는 계열: K 는 항상. L 은 Z≥20 이고 주선 ≥ 0.8 keV 일 때(Ni·Cu Lα 포함). M 은 Z≥57 이고 주선 ≥ 0.8 keV 일 때.
    - window 안에 모형이 설명하지 못한 counts 가 3σ 이상, 신호의 10 % 이상 남으면 'window residual 큼'으로 알린다. 원인은 목록에 없는 원소, 선 모양 차이(특히 M 계열), escape·sum peak 일 수 있다.
    - alternative의 예상 상대오차가 25 % 안쪽이면 'alternative와 비슷'을 붙인다. 추천이 M 계열이고 alternative가 L 이면, 정량할 때는 L 과 교차 확인한다.
  - **파일이 없으면 모형값**을 쓴다.
    - intensity ∝ 조성 × n_s·ln(U)/E_c (Bethe) × 형광수율·branching (xraydb) × windowless Si 검출효율.
    - 조성은 '조성 (선택)' 칸에 상대 원자비로 넣는다. 비우면 모두 같은 비율로 계산한다.
    - 같은 계열 안의 선 비교는 믿을 만하다. 그러나 K/L/M **계열 사이 비는 수 배까지 틀릴 수 있다.** 이 모형은 F K 대비 Lu·Tm L 의 원자당 세기를 약 3.2배로 계산하는데, 이 앱에 저장된 NaLnF4 실측 k-factor(Lu_L 2.10, Tm_L 2.03)가 뜻하는 값은 약 0.48배다.
    - 그래서 모형 모드에서 계열이 다른 alternative와 3배 안쪽으로 가까우면 '계열 선택은 실측 확인'을 붙인다.
- 각 행의 작은 그림은 라인 ± 3·FWHM 구간이다.
  - 그 원소의 선, 다른 원소의 선, 배경, 실측 스펙트럼(파일이 열려 있을 때)을 겹쳐 그린다.
  - 적분 window 는 음영으로 표시한다.
- 넣지 않은 것: escape·sum peak, 시료 자체 흡수.
- CSV 로 추천 결과를 내보낼 수 있다(`eds_line_recommendation.csv`).
- **합성 시험** (`modules/interf/test/`):
  - 조성을 아는 Velox .emd 로 NNLS counts 를 참값과 비교했다.
  - 주성분(Na, F, Lu L·M, Yb L·M): ±5 % 이내.
  - 2 % Tm L: +3 %. 배경 기저 설정에 따라서는 ±40 % 까지 흔들린다.
  - 0.6 keV 아래 선(C, O)은 합성 연속선이 가팔라 크게 틀렸다.
- **실측 파일 시험** (연구원 제공 Velox .emd, Super-X 4분할 합, 200 kV, 원소 C·O·F·Na·Si·Ni·Cu·Lu·Tm·Yb):
  - 모형 + 배경이 데이터를 채널당 χ² 0.9–2.9 로 설명했다. C K 대역은 꼬리 모형을 넣기 전 339 였고, 넣은 뒤 3.8 이 됐다.
  - 추천 결과
    - Lu: Mα (Lα 는 Ni Kα 7.478 keV 와 177 eV 차이로 겹친다. alternative는 Lβ1).
    - Tm: Mα, alternative Lα1,2 와 비슷하다.
    - Ni·Cu·Si: Kα.
    - Yb: 신호 부족(이 시료에서 사실상 없음).

### 전체 겹침 목록

선택한 원소들의 방출선을 모두 꺼내 쌍마다 ΔE 와 그 에너지에서의 FWHM 을 비교한다.

| ΔE / FWHM | 판정 |
|---|---|
| < 0.5 | 분리 불가 |
| < 1.0 | 부분 겹침 |
| < 2.0 | 주의 |

### 두 입력값이 어디서 오는가

이 탭의 판정은 **FWHM(Mn Kα)** 와 **에너지 상한** 두 값에 통째로 의존하므로, 각 값 옆에
출처 배지를 붙여 두었다. 근거 없는 숫자로 판정하고 있지 않은지 한눈에 보라는 뜻이다.

| 배지 | 뜻 |
|---|---|
| `제로 스트로브 실측` | 열린 파일의 제로 피크 폭에서 직접 잰 분해능 (권장 상태) |
| `파일 분해능 모형` | 파일이 분해능 모형을 직접 담고 있음 (Bruker `SigmaAbs`/`SigmaLin`) |
| `파일 메타데이터` | 제로 피크를 못 재서 메타데이터값을 그대로 씀 |
| `4096 ch × 5 eV` | 상한 = offset + dispersion × (채널수 − 1), 즉 **실제 취득 범위** |
| `기본값 · 파일 없음` | 파일이 없어 관례값(130 eV / 20 keV)으로 계산 중 — **이 장비의 실측값이 아님** |
| `직접 입력` | 손으로 고친 값. 파일 근거를 주장하지 않는다 |

파일 없이 열면 경고 상자가 뜬다. 그 상태의 130 eV 는 SDD 통상 범위(125~140 eV)에서 고른
둥근 수일 뿐이고, 20 keV 도 4096 ch × 5 eV 취득의 대략적 범위일 뿐이다. 판정 자체는
돌아가지만 참고용으로만 쓸 것 — 특히 **dispersion 을 바꿔 찍은 데이터**에서는 상한이
어긋나 진짜 겹침을 놓치거나 기록되지도 않은 라인을 경고한다.

> 벤더 스펙시트의 분해능은 **규정 조건에서의 보증 상한**이지 그날 그 계수율에서의 실제
> 분해능이 아니다. 스펙값은 실측값의 **대체물이 아니라 위생 검사용 상한**으로만 쓴다.
> 앱은 파일의 `Instrument.InstrumentModel` 로 장비를 조회해 실측과 스펙을 나란히 보여 준다
> (스펙트럼 탭 상단 상자). 실측이 스펙보다 **좋으면 정상**, **넘으면 점검 신호**다.

CSV 로 내보내 실험 노트에 붙일 수 있다. 내보낸 CSV 에는 판정에 쓰인 FWHM·상한과 그
출처가 `basis_*` 열로 함께 들어가므로, 나중에 그 파일만 봐도 무엇을 가정했는지 알 수 있다.

## 장비 스펙 대조 · 검출기 기하

앱은 `Instrument.InstrumentModel` 로 `INSTRUMENTS` 레지스트리를 조회한다. 등록된 장비면
스펙트럼 탭 위에 **실측 vs 스펙** 상자가 뜬다. 레지스트리 항목에는 반드시 **출처(src)**를
적는다 — 근거 없는 숫자를 앱이 사실처럼 말하지 않게 하려는 것.

현재 등록: **Talos F200X** — 200 kV · EDS 분해능 스펙 **136 eV** · Super-X **4× windowless SDD**
(출처: 연구실 제공 장비 상세사양). 실측은 **129.2 eV**로 스펙보다 6.8 eV 좋다.

파일에서 함께 읽어 타일로 보여 주는 것들:

| 항목 | Example #1 값 | 왜 중요한가 |
|---|---|---|
| take-off 각 (`ElevationAngle`) | **22.0°** | 흡수 보정의 전제 |
| 방위각 (`AzimuthAngle`) | 45 / 135 / 225 / 315° | Super-X 4분할의 4회 대칭 |
| 성형시간 (`PulseProcessTime`) | **3.0 µs** | 분해능–계수율 절충의 설정값 |
| 데드타임 (ICR→OCR) | 2.3~3.4% | 이 낮은 계수율이 스펙보다 좋은 분해능의 이유 |

**windowless 의 함의** — 창 흡수가 없으므로 저에너지 꼬리는 창이 아니라 **불완전 전하수집·
Si 데드레이어**에서 오는 것으로 해석해야 하고, 경원소(C·O·F) 세기에 창 감쇠 보정이 필요 없다.
대신 오염·결빙에 취약하므로 저에너지 응답이 시간에 따라 나빠졌는지는 따로 봐야 한다.

### 세그먼트별 분해능

Super-X 는 독립 SDD 4개다. 합산 스펙트럼 하나만 보면 어느 세그먼트가 나쁜지 알 수 없으므로
세그먼트별 σ₀ 를 표로 보여 준다. 실측 파일 2건에서:

| 세그먼트 | 방위 | σ₀ (파일 A / B) | FWHM | ICR (A) |
|---|---|---|---|---|
| SuperXG21 | 45° | 17.80 / 17.85 | 130.0 | 658 |
| SuperXG22 | 135° | 16.75 / 16.81 | 129.2 | 1379 |
| SuperXG23 | 225° | 16.22 / 16.21 | 128.9 | 2150 |
| SuperXG24 | 315° | 16.17 / 16.18 | 128.8 | 1457 |

계수율이 3배 달라도 σ₀ 는 **±0.06 eV** 로 재현된다. 즉 세그먼트 차이는 **각 SDD 의 고정된
전자 노이즈**이지 계수율 효과가 아니다 — 계수율이 가장 낮은 G21 이 오히려 가장 넓다.
세그먼트마다 계수율이 다른 것은 시료·홀더 **그림자** 때문이므로 분해능과 혼동하지 말 것.

### 제로피크 측정이 믿을 만한 조건

제로 스트로브 폭 측정은 **분산이 촘촘할 때만** 믿을 수 있다. 실측 비교:

| 분산 | 제로피크에 걸린 채널 | 실측 FWHM | 대조값 |
|---|---|---|---|
| 5 eV/ch | ≈ 13 ch | **129.2 eV** | 스펙 136 eV 아래, 정상 |
| 10 eV/ch | ≈ 9 ch | 133.3 eV | 같은 파일의 분해능 모형 **128.6 eV** 보다 3.6% 넓음 |

채널이 적으면 로그-포물선 적합이 폭을 **과대평가**한다. 그래서 앱은 ① 파일이 분해능 모형을
직접 담고 있으면 그쪽을 우선하고, ② 제로피크에 걸린 채널이 12개 미만이면 타일에
`제로피크 N ch — 과대평가 가능` 을 붙인다.

> 이전 판에서 Bruker 파일의 128.6 eV 를 "독립 교차검증"이라 적었는데 정확하지 않다.
> 그 파일도 200 kV · SuperX EDS 로 기록돼 있어 **같은 검출기일 가능성이 높다**. 따라서
> 그것은 검출기의 독립 검증이 아니라 **측정 방법의 검증**이다. 장비 스펙 136 eV 가
> 지금으로서는 유일한 독립 기준이다.

## Energy Diagram (에너지 준위 도식)

파일 없이 쓰는 탭이다. 이 탭에서는 왼쪽 파일 열을 숨긴다.

### 입력

- **화학식**: `β-NaYF4:20%Yb,2%Er`, `NaY0.78Yb0.2Er0.02F4`, `Na(Y0.78Yb0.20Er0.02)F4`, `NaGdF4:Yb,Tm@NaGdF4:Tb`(코어@셸), `K2SiF6:Mn4+`, `CaF2:Eu2+`.
  아래첨자·위첨자 유니코드(₄, ³⁺)도 읽는다.
- **농도**: 호스트 식 안에 활성 원소가 있으면 **같은 자리 원소 합에 대한 비율**로 계산한다(NaY0.78Yb0.2Er0.02F4 → Yb 20 %, Er 2 %).
  도펀트 표기의 1 이하 숫자는 분율로 본다(`Yb0.2` = 20 %).
- **산화수**: 명시하면 그대로 쓴다. 명시하지 않으면 치환 자리의 원자가로 정한다.
  - Mn: Si⁴⁺ 자리면 Mn⁴⁺, Zn²⁺ 자리면 Mn²⁺.
  - Eu: 2가 양이온만 있는 호스트(CaF₂ 등)면 Eu²⁺. 산화 분위기에서 합성했다면 Eu³⁺ 일 수 있다는 경고가 함께 뜬다.
  - 3가 이온이 2가 자리에 들어가면(KPb₂Cl₅:Nd 등) 전하 보상 결함 경고가 뜬다.
- **주기율표**: 색이 칠해진 원소가 준위 데이터를 가진 원소다. 누르면 산화수를 골라 열로 추가한다.
- 통상 원자가로 전하 합이 맞지 않는 식은 경고한다.

### 준위값은 어디서 오는가

| 이온 | 출처 | 비고 |
|---|---|---|
| Ln³⁺ (Ce–Yb) | Carnall et al., J. Chem. Phys. 90, 3443 (1989) — LaF₃ Stark 준위 표 | 652개 multiplet, 52,000 cm⁻¹ 까지 |
| Sm²⁺, Eu²⁺, Tm²⁺, Yb²⁺ | NIST ASD 자유 이온 준위 | 4fⁿ⁻¹5d 밴드는 **호스트 의존 매개변수** |
| Ce³⁺ 5d | 매개변수 | 기본값 LaF₃ ≈ 250 nm 는 근사값 |
| Cr³⁺, Mn⁴⁺, Mn²⁺, Ni²⁺ | Tanabe–Sugano (정확한 dⁿ 대각화 격자에서 보간) | Dq·B·C 입력. 기본값은 표지된 참조 호스트 |

**Ln³⁺ 준위값을 얻은 방법**

- 디지털화된 Carnall 표는 겹친 multiplet에 한 이름을 내려 붙여 둔 곳이 많다.
- 그래서 같은 파라미터로 해밀토니안을 다시 대각화하고, 고유벡터가 가장 크게 투영되는 multiplet에 각 Stark 준위를 귀속했다. 재계산값과 Carnall 계산값의 rms 차이는 이온별 0.3–16 cm⁻¹ 다. 예외는 Yb 로 70 cm⁻¹ 인데, 결정장 파라미터를 Tm 에서 빌려 왔기 때문이다.
- 준위선은 **multiplet barycenter**, 옅은 띠는 **Stark 범위**다.
- 문헌 대표 파장 59개는 모두 바리센터 차이로 계산한 λ 와 **2 % 안**에서 일치한다(시험 코드로 고정).

> **함정** — 이 값은 LaF₃ 기준이다.
> - 다른 불화물에서는 수십 cm⁻¹, 산화물에서는 수백 cm⁻¹ 까지 이동한다.
> - 바리센터는 흔히 인용되는 '최저 Stark 준위' 값보다 100–250 cm⁻¹ 높다(예: Yb ²F₅/₂ 10,450 vs 최저 10,260).
> - Er 의 ≈24,700 cm⁻¹ 준위는 Carnall 표기로는 ²G₉/₂ 이지만 UCNP 문헌 관례를 따라 ²H₉/₂ 로 표시한다.

### multiphonon 판정

p = (아래 준위와의 **가장자리 간격**) / ħω_max 로 판정한다.

| p | 판정 | 도식 표시 |
|---|---|---|
| < 5 | multiphonon 우세 | 옅은 선 |
| 5–8 | 경쟁 | 중간 굵기 |
| ≥ 8 | 복사 우세(metastable) | 굵은 선 |

- 이 경계는 경험칙이라 호스트와 온도에 따라 움직인다.
- dⁿ 이온은 간격 법칙 대신 **가장 낮은 들뜬 준위로 빠르게 모인다**(Kasha 형)고 둔다.
- ħω_max 는 호스트 표에서 가져오고, 출처를 확보한 호스트만 '출처' 표지가 붙는다.
- β-NaGdF₄·β-NaLuF₄ 는 출처를 찾지 못해 동형인 β-NaYF₄ 값(360)을 빌려 쓰고 **'추정'** 으로 표시한다.

### 에너지 전달 판정

- **resonant**: donor 전이와 acceptor 전이의 **Stark 창**(가능한 Stark–Stark 조합 전체 폭)이 겹치면 resonant이다.
  - 창은 겹치지만 중심 불일치가 ħω 보다 크면 **'resonant(Stark 끝)'** 으로 따로 표시한다.
- **겹치지 않을 때**: 남는 간격 δ 를 ħω 로 나눠 1-포논, 2-포논, 3–4 포논으로 매기고, 그보다 크면 non-resonant이다.
- **endothermic**: 포논을 흡수해야 하는 과정은 exp(−δ/kT) 를 따로 보인다. T 는 조성 카드에서 바꿀 수 있다.
- **종류 자동 판정**:

| 조건 | 종류 |
|---|---|
| acceptor 가 바닥에서 출발, donor 도 바닥으로 | ET |
| acceptor 가 바닥에서 출발, donor 는 중간 준위로 | CR |
| 활성 이온에서 sensitizer 이온(Yb³⁺·Nd³⁺·Ce³⁺)으로 되돌아감 | BET |
| acceptor 가 여기 상태에서 출발 | ETU |
| 같은 전이를 맞교환 | EM |
| '협동'을 켜면 donor 에너지 ×2 | CET |

  자동 판정 결과와 다르게 부르고 싶으면 상세 칸에서 바꿀 수 있다. 예: Tm 의 ³F₂+³H₄→³H₆+¹D₂ 는 문헌에서 흔히 'cross-relaxation'이라 부르지만, 이 기준으로는 ETU 다.

> **함정** — Stark 창 판정은 상온에서 위쪽 Stark 준위가 population이 적다는 점을 반영하지 않는다. 그래서 창 가장자리끼리의 resonant은 실제보다 유리하게 보인다.
> 이 판정은 **에너지 정합성만** 본다. 전달 속도(거리·농도·다중극 세기)는 DRE 에서 다룬다.

### 이온 간 상호작용 (서로 다른 이온이 2종 이상일 때)

Yb³⁺–Tm³⁺ 처럼 서로 다른 이온이 들어 있으면 '이온 간 상호작용' 카드가 나온다.

- **행렬**: 방향마다 하나씩 그린다(A→B, B→A). back transfer 도 함께 본다.
  - 행은 donor 의 여기 준위, 열은 acceptor 의 바닥·metastable 준위다.
  - 칸에는 두 준위 사이에서 에너지가 가장 잘 맞는 조합의 필요 포논 수 N = δ/ħω 를 적는다. δ 는 Stark 창 간격이다.
  - endothermic 이면 detailed balance 인자 exp(−δ/kT) 를 ↑ 로 붙인다.
  - 칸을 누르면 그 칸의 모든 조합이 아래 목록에 나오고, ＋ 로 도식에 추가한다.
  - 필요 포논 수 상한(2–8)은 고를 수 있다. 도식의 축 상한과 무관하게 40,000 cm⁻¹ 까지 본다.
- **확률로 읽을 수 있나**: 없다. 이 표는 에너지 조건만 본 상대 순위다.
  - 실제 전달 속도는 두 전이의 선세기·선모양 겹침과 이온 간 거리 분포에 각각 수 자릿수씩 좌우된다. 이 둘은 준위 에너지만으로 정해지지 않는다.
  - 예: Yb→Tm ³H₆→³H₅ 는 δ ≈ 1,300 cm⁻¹ (포논 3.6개)인데도 실측에서 효율적이다.
- **절대 전달 효율**: 측정된(또는 같은 호스트 문헌의) microparameter C_DA 가 있을 때만 계산한다.
  - 입력: C_DA, donor 고유 수명 τ_D, acceptor 농도, 양이온 자리 밀도.
  - 식: 정적 Förster 평균(dipole–dipole, acceptor 무작위 분포, donor 간 이동 없음; Förster 1949, Inokuti & Hirayama 1965).
    - R₀⁶ = C_DA·τ_D, c₀ = 3/(2π^{3/2}R₀³), γ = (√π/2)·N_A/c₀, η = √π γ e^{γ²} erfc γ.
  - Yb³⁺ 처럼 donor 간 energy migration 이 빠르면 이 값은 하한이다.
- 시험: `test/test_interion.js` (12항목). erfcx 는 수치적분과 10⁻⁶ 안에서 맞고, η 는 γ→0 에서 √πγ, γ→∞ 에서 1 로 간다.

### 광흡수·photon avalanche 점검

- **여기 광원**: 파장(nm)을 여러 개 넣을 수 있다. 각 파장에 대해 다음을 자동 후보로 그린다.
  - **GSA**: 3–4 포논 불일치까지
  - **ESA**: population이 생길 수 있는 복사 우세 준위에서 출발하는 것만, 1-포논까지, 두 단계까지
- **PA 루프 후보**: 다음 세 조건이 모두 성립하면 표시한다(Joubert 1999; Lee et al. 2021).
  1. GSA 가 2-포논 이상 벗어남
  2. metastable 준위 M 에서 resonant ESA
  3. 그 도착 준위가 흘러내린 준위 H 가 바닥 이온과 cross-relaxation해 M 두 개를 만듦
- 예: β-NaYF₄:Tm 1064 nm 에서 나오는 결과

| 과정 | 판정 |
|---|---|
| GSA ³H₆→³H₅ | 3–4 포논 |
| ESA ³F₄→³F₂ | resonant |
| CR ³H₄+³H₆→³F₄+³F₄ | 2-포논 |

  Er 980 nm, Tm 800 nm 처럼 GSA 가 resonant이면 후보로 올리지 않는다.

> 이 점검은 준위 구조상 **필요조건**만 본다. avalanche가 실제로 일어나는지는 σ_ESA/σ_GSA, CR 속도(농도), metastable 수명에 달려 있다.

> Energy Diagram — 광자 사태 루프 후보의 '도식에 루프 추가'는 같은 과정을 두 번 넣지 않는다. 추가한 루프는 같은 자리의 '도식에서 이 루프 제거'로 뺀다. 과정 표의 × 는 하나씩, '모두 지우기'는 전부 지운다(준위·이온은 그대로). 예전 판에서 쌓인 똑같은 과정은 불러올 때 하나로 합친다. 루프를 다시 눌러도 늘어나지 않는다.

## DRE (rate equation 시뮬레이션·피팅)

파일 없이 쓰는 탭이다. 계산은 브라우저 안에서 하고, 피팅은 Web Worker 에서 돌린다(화면이 멈추지 않고, 중단할 수 있다).

### 모델

- **Tm³⁺ 3준위 PA (Lee et al., Nature 589, 230 (2021))**
  - 공개 코드의 식과 값을 그대로 옮겼다. 코드 주석은 σ 단위를 cm² 라 적었지만 실제 계산은 m² 이라, cm² 로 바꿔 넣었다.
  - 농도 의존도 코드 그대로다: s₃₁ = k₃₁·c², Q = k·c³/(c²+4.3²).
- **Energy Diagram 도식에서 가져오기**
  - 그려 둔 광흡수·에너지 전달·이완을 연립 rate equation 으로 만든다.
  - 모든 계수는 **placeholder 값**으로 시작하고, 표에 노란색으로 표시된다. 문헌·측정값으로 바꾸기 전의 곡선은 형태 참고용이다.
  - 감쇠가 하나도 없는 들뜬 준위에는 바닥으로의 총 감쇠를 자동으로 붙인다. 없으면 population이 쌓여 정상상태가 존재하지 않는다.
  - 에너지 전달은 mean-field 형태다: donor 감소 W·x_A, acceptor 증가 W·x_D (x = mole fraction).
- 매개변수는 식으로 쓸 수 있다. 예: `(1-b32)*w3r`, `k31*c^2`. 쓸 수 있는 연산은 + − × ÷ ^ ( ) 와 이름뿐이다.

### 수치 방법 — 왜 이 방식인가

- **정상상태는 적분이 아니라 근 찾기로 푼다.**
  - 앞 파워의 해에서 Newton(선 탐색)으로 시작한다.
  - branch가 사라지면(threshold) implicit Euler pseudo-time으로 다음 안정 상태까지 흘려보낸 뒤 Newton 으로 마무리한다.
  - 그래서 up·down 스윕이 측정처럼 안정 branch를 따라가고, bistable이면 히스테리시스가 그대로 나온다.
- **동역학**: L-안정 TR-BDF2 와 단계 배가 오차 제어를 쓴다. 상승·감쇠 시간은 목표에 도달하면 적분을 끝낸다.
- **감도**: implicit function theorem dn/dθ = −J⁻¹∂f/∂θ 로 구한 정확한 값이다. 차분이 아니다.
- **가우시안 빔(앙상블)**: ∫₀^{I₀} y(I) d ln I.
  - 구간마다 거듭제곱 법칙으로 적분하고 Richardson 외삽을 한다.
  - threshold의 가장 급한 점에서 오차는 약 0.5 %, 그 밖에서는 10⁻⁴ 이하다.
  - 단일입자 측정이면 **peak intensity**를 쓴다.

> **함정 — '0.5 s 적분 = 정상상태'**: Lee 공개 코드는 0.5 s 까지 적분한 값을 정상상태로 쓴다. 이 모델의 threshold(7 kW/cm²)에서 95 % 상승 시간은 **0.64 s** 이고, 0.5 s 에서의 값은 정상상태의 **83 %** 다. 기울기가 가장 가파른 곳에서 곡선이 왜곡된다.

### 데이터

- **S-curve**: 파워와 **배경을 뺀 신호**를 넣는다.
  - 붙여넣기나 CSV 모두 된다. 열마다 채널을 지정하면 여러 채널을 한 번에 넣을 수 있다.
  - 배경 σ 의 k 배(기본 3) 아래 점은 버리지 않고 **censored(상한)** 으로 쓴다. 모델이 상한을 넘을 때만 벌점을 준다.
  - 0 을 log 에 넣지 않는다. 결측은 NaN 으로 둔다.
- **상승 시간 · 감쇠 1/e 시간**: 파워와 시간(s)을 넣는다. 절대 시간 스케일을 고정하는 데이터다(아래 identifiability 참조).
- **시료**: 농도 계열은 시료를 나눠 넣는다. 비복사 손실만 '시료별'로 두고 나머지는 공유하면 전역 피팅이 된다(Lee 2021 코드가 쓰는 방식).
- **합성 데이터 만들기**: 현재 매개변수를 참값으로 삼아 잡음 있는 S-curve 를 만든다.
  - 참값은 데이터에 함께 저장되고, 결과 표에 log₁₀(최적/참값) 열이 붙는다.
  - 피팅 전략과 identifiability를 시험하는 용도다.

### 피팅

- **탐색**: log₁₀ 공간 Latin hypercube multi-start → Levenberg–Marquardt(box constraints, gain ratio 갱신)
- **residual**: (ln y − ln ŷ − ln s)/σ, σ² = multiplicative noise² + (배경σ/y)²
  - 배율 s 는 데이터셋마다 닫힌해로 소거한다. 검출 효율과 gain 을 몰라도 된다.
- **결과**
  - **waterfall**: 출발점별 최종 χ². 'global minimum 도달 n/N' 은 최소 χ² 에서 0.5 이내로 끝난 출발점 수다.
  - **profile likelihood 95 % 구간**: Δχ² ≤ 3.84·max(1, χ²/자유도). 구간 끝이 탐색 범위(±span 또는 경계)에 닿으면 '열림'으로 표시한다. 그 방향으로는 데이터가 값을 정하지 못한다는 뜻이다.
  - **FIM eigen-decomposition**: 가장 잘 정해지는 방향과 가장 덜 정해지는 방향을 매개변수 조합으로 보인다.

### Tm 5·6준위 모델

'모델 바꾸기'에서 고른다. 값은 Chen 2025(NaLuF₄:Tm 8준위, SI Table 3)와 Lee 2021(JO 복사율, Q 계수)에서 가져왔고, 매개변수 표에 출처가 적혀 있다.

| 모델 | 준위 | 과정 |
|---|---|---|
| 5준위 | ³H₆ ³F₄ ³H₅ ³H₄ ¹G₄ | GSA ³H₆→³H₅, ESA1 ³F₄→³F₂,₃(→³H₄), ESA2 ³H₄→¹G₄, CR1 (³H₄,³H₆)→(³F₄,³F₄), ETU 2종, 각 준위 감쇠·분기 |
| 6준위 | + ¹D₂ | + CR2 (³H₄,¹G₄)→(³F₄,¹D₂) — 450 nm 경로 |

- 전달 계수는 cm³ s⁻¹ 이고, 속도는 계수 × Tm number density(NRE × c/100)다. 시료 변수 c 는 Tm %.
- 채널: 800 nm, 475 nm, 450 nm(6준위), 청색 450+475(6준위), **NIR 필터 (800 + ¹G₄→³H₅ 780)**, 1.8 µm. 우리 NIR 광학계(950 DMSP + 750 LP + 850 SP)는 750–850 nm 를 통과하므로 780 nm 가 들어온다 — NIR S-curve 는 'NIR 필터' 채널로 맞춘다. 가중치는 기본값의 방출 속도라 채널 사이 비율에만 의미가 있다.
- 3준위 극한(σ_ESA2 = 0, ³H₅ 즉시 이완)에서 Lee 템플릿과 10⁻⁸ 까지 같고, 손으로 적은 scipy 구현과 정상상태 10⁻¹⁰·동역학 10⁻⁷ 로 일치한다 (`test/test_tm5.js`, `test/tm5_scipy.py`).
- 비복사 w2nr·w3nr 는 placeholder 값이다. 시료마다 수명으로 정한다.

### 데이터 점검 — 넣은 데이터의 입력 실수를 먼저 잡는다

데이터마다 아래를 검사해 목록에 표시한다. '피팅 전 고칠 것'이 남아 있으면 피팅을 시작하지 않는다. 대부분은 목록의 단추로 바로 고친다.

| 검사 | 기준 | 단추 |
|---|---|---|
| up·down 섞임 (피팅 막음) | 한 S-curve 에서 파워가 최대까지 오른 뒤 다시 30 % 넘게 내려감 | up·down 나누기 |
| rise/decay 시간 값 비정상 (피팅 막음) | 1 ns–10⁴ s 밖 (예: pulse CSV 첫 행 카운터 누적값) | 이 데이터 삭제 |
| 배경을 빼지 않은 것으로 보임 | 낮은 파워 바닥 평균이 점 간 SD 보다 크고 평균의 표준오차의 5배를 넘음 | 배경 추정·빼기 (되돌리기 가능) |

- 배경 추정: 파워 순으로 낮은 15 % 점의 중앙값·MAD 로 바닥을 잡는다. 바닥(중앙값 + 6·MAD) 안쪽 점에 상수 + 파워 비례 직선을 맞춰 빼고, 그 산포를 배경σ 로 쓴다. 0 이하가 된 점은 censored 로 들어간다.
- 적합성 A2(runs test)는 이제 z > +3 도 경고한다. 부호가 우연보다 훨씬 자주 바뀌면, 같은 파워에서 값이 다른 두 집단(up·down 혼합 등)이 번갈아 섞였다는 신호다.

### 데이터 넣기 — CSV

- **S-curve CSV**
  - 파워 열은 이름(Power·Intensity)으로 고른다.
  - σ 열(Std·SD·σ·Err)이 있으면 점별 σ 로 쓴다. 반복 측정 SD 는 반복 수 n 으로 나눠 평균의 σ 로 쓰고, n 은 파일 이름의 rep 숫자에서 읽는다. 점별 σ 와 배경σ 는 제곱합으로 합친다.
  - Interp 열이 True 인 보간 행은 기본으로 뺀다.
  - 파워가 최대에서 되돌아가면 up·down 을 자동으로 나눈다.
  - 배경 자동 추정·빼기가 기본으로 켜져 있다.
- **pulse 응답 CSV** (Time, Counts, SetV, Power — ScopeFoundry ni_daq_pulse_resp 내보내기)
  - 헤더로 알아보고 '시간 트레이스'(진단용)로 넣는다.
  - 첫 행 Counts 가 나머지의 100배 이상이면 카운터 누적값으로 보고 버린다.
  - on/off 는 SetV 로 찾고, 파워는 Power 열 첫 값이다.
  - on 구간을 최대 2,000점으로 평균 묶음한다.
  - 넣기 전에 배경, plateau, rise t10·t50·t90, 끈 뒤 절반까지의 시간을 보여 준다.
  - rise t90 이 10 s 를 넘으면 경고한다. 켤 때와 끌 때가 비대칭이면 준위 수명(ms)으로 정해지는 정상상태 DRE 밖의 느린 변수일 수 있으므로, rise 제약으로 쓰지 않는다.
- **파워 열이 무엇인지는 데이터마다 다르다.** 보정이 끝난 시료면 intensity 일 수도, 파워미터 값일 수도 있다.
  - 단위 목록에서 'intensity (보정 끝남 · 시료면)' 또는 '파워미터 파워 (보정 필요)'를 고른다.
  - 마지막 선택은 표 CSV 와 pulse CSV 따로 기억한다.
  - 파일 이름에 파워 표기(예: 8uW)가 있고 파일 안 값과 다르면, 둘을 나란히 보여 준다.
- 사례 (DY033, 2026-09-30)
  - 섞인 up·down, 잘못 들어간 rise 4점, 빼지 않은 배경을 고치자 χ²/자유도가 3043 에서 6.0 으로, 피팅 시간이 2262 s 에서 87 s 로 줄었다.

### 데이터 넣기 — .h5 원시 파일

'시료·데이터 → 파일'에서 .h5 를 고르면 형식을 알아본다.
- **power_scan**: apd_counter_powers(W)·count_rates·wheel_positions 로 up·down을 나눈다. 파워 환산 프리셋(NIR 268.13, Blue 381.27 잠정 kW/cm² per mW) 또는 직접 입력. 배경은 up branch 첫 점프 이전 점들의 직선(상수 + 파워 비례)으로 제안한다. 반복 5회 안에서 전환된 점(CV > 0.3)은 뺄 수 있다.
- **ni_daq_pulse_resp**: set_voltages 로 켬·끔 구간을 찾고, 첫 샘플이 카운터 누적값이면 버린다. 배경은 켜기 전 평균, 파워는 파일의 power_meter_2 값(펄스 중이면 평균일 수 있으니 확인). 진단용 시간 트레이스로 들어간다.

### 데이터별 파워 보정

붙여 넣는 데이터는 대개 파워미터(PM) 값이거나 휠 각도뿐이다. 그래서 데이터마다 보정 상태를 기록하고, 목록의 **'파워 보정'** 단추로 바로 고친다.

- **단위 고르기**
  - CSV·붙여넣기의 단위 목록은 'intensity(이미 보정됨)'와 '파워미터 값(보정 필요)' 둘로 나뉜다.
  - 파워미터 단위를 고르면 마지막으로 쓴 보정(없으면 NIR 프리셋)이 임시로 붙는다. 목록에 **'보정 확인'** 표시가 뜬다.
  - 이 상태로 피팅하면 피팅 화면에 경고가 뜬다.
- **식**: I [W/cm²] = P_PM [W] × C × 10⁸ / A_peak [µm²] × 추가 배율, A_peak = πw²/2.
  - C 는 PM→시료면 투과 보정이다.
  - 프리셋
    - NIR 950 DMSP Oil: C 3.323, A 1.2393 µm², 268.13 kW/cm² per mW.
    - Blue 600 DMSP Oil: 잠정값, A 0.8715 µm², 381.27.
  - 직접 입력도 된다. 빔 반경 w, 또는 kW/cm² per mW 값을 바로 넣을 수 있다. PM 파장 보정 비(측정 파장 설정이 틀렸을 때)도 넣을 수 있다.
- **휠 각도만 있을 때**
  - '휠 각도로 복원'을 켠다. (각도, PM 값) 기준점 3개 이상을 넣고 '자동 맞춤'을 누른다.
  - 편광자 a·cos²(θ−θ₀)+b, 반파장판 a·cos²(2(θ−θ₀))+b, 연속 ND a·10^(−k(θ−θ₀))+b 세 모델을 모두 맞춘다. 상대 rms 가 가장 작은 모델을 쓰고, 나머지 모델의 rms 도 함께 보인다. 모델 사이 rms 차가 작으면 기준점을 늘린다.
  - 시험: WJ-0128c 휠 기준점 4개로 복원한 파워는 PM 대비 0.94–1.09 였다.
- **적용 범위**
  - '이 데이터', '이 시료 전체', '모든 데이터' 중에서 고른다. 여러 개에 적용할 때는 개수를 확인받는다.
  - 원시 값(PM 또는 휠)은 따로 보존된다. 보정을 바꾸면 intensity가 다시 계산되므로 여러 번 고쳐도 누적되지 않는다.
- **프로필 저장**: 광학계별 C·A_peak 를 이름 붙여 이 브라우저에 저장한다(`innoanalytics_dre_cal_v1`).
- **.h5**: 가져올 때 고른 프리셋이 확정 보정으로 기록된다. 파일에 있는 휠 위치도 함께 보존한다.

### 병렬 피팅 — 이 컴퓨터에 맞춘 워커 수

- multi-start 출발점과 매개변수별 프로파일, χ² slice 격자 행을 여러 Web Worker 에 나눠 돌린다. 먼저 끝난 워커가 다음 일을 가져가는 동적 분배라 성능·효율 코어가 섞인 CPU 에서도 놀지 않는다.
- 워커 수 0(기본) = 자동. 첫 피팅 때 약 3–4초 동안 워커 1, 2, 4, … 개로 실제 DRE 연산(정상상태 스윕 + 감도) throughput을 재고, 최고 throughput의 95 % 안에서 가장 적은 워커 수를 고른다. 결과는 이 브라우저에 저장되고 피팅 탭에 확장 곡선으로 보인다('다시 측정').
- 브라우저는 논리 스레드 수만 알려 준다. 물리 코어는 효율(속도비/워커 수) ≥ 80 % 가 유지되는 최대 워커 수로 추정하고, 그 위 스레드(SMT·효율 코어)의 추가 이득을 따로 표시한다.
- 병렬 결과는 직렬과 출발점별 χ²·최적값·프로파일 구간까지 같다(`test/ui_pool.py`).
- **CPU 사용 한도**(기본 '균형 75 %')
  - 선택지: 최대 100 %, 90 %, 균형 75 %, 여유 50 %, 백그라운드 25 %.
  - 워커 수는 floor(논리 스레드 × 한도)를 넘지 않는다. 측정된 최적 워커 수도 넘지 않는다.
  - 브라우저는 스레드 우선순위를 낮출 수 없다. 그래서 스레드를 비워 두는 방식으로 다른 프로그램의 응답성을 지킨다.
  - 선택 옆에 예상 CPU 점유율과 '속도 최대의 x %'가 표시된다. 속도는 측정한 확장 곡선을 보간한 값이다.
  - SMT CPU 에서는 물리 코어 수까지만 써도 속도의 대부분이 나온다. 예: 8스레드·4코어 곡선에서 50 % 한도면 최대 속도의 76 %.
  - 피팅 중에 바꿔도 된다. 진행 중인 계산이 끝나는 대로 워커를 줄이거나 늘린다. 결과는 워커 수와 무관하게 같다(`test/ui_cpu.py`).
  - 처음 한 번 하는 scaling 측정(약 3–4초)만은 모든 스레드를 잠깐 쓴다.

### 피팅 상세 분석 — 판단 근거

피팅 결과 아래에 한 줄 신호등(전역 최소 · identifiability · 모델 적합성 · residual 크기)과 펼쳐 보는 여섯 절이 나온다. 펼침 상태는 기억된다.

| 절 | 보여 주는 것 | 읽는 법 |
|---|---|---|
| ① 모델 적합성 | A1–A6 판정 (아래 표) | '실패'가 하나라도 있으면 피팅값을 물성으로 보고하지 않는다 |
| ② 매개변수별 근거 | 프로파일 95 % 대 곡률(Wald) 95 % 비교, 정보 기여 히트맵, 프로파일 곡선 | 두 구간이 다르면 비선형 — 곡률 구간만 쓰면 과신. 기여가 한 파워 구간에 몰리면 그 몇 점이 값을 좌우 |
| ③ 종속성·독립성 | 상관행렬, FIM eigenvector 막대, 보상 궤적(한 값을 고정해 옮길 때 나머지의 재최적화 경로) | \|ρ\|→1 이거나 궤적 기울기 −1 이면 곱·비만 정해진다 |
| ④ χ² landscape | waterfall, 해 집단(χ² 수준별 출발점 수·값 범위), 끝점 쌍 산점도, 두 매개변수 χ² slice(버튼, 17×17) | 같은 χ² 수준에서 값이 넓게 퍼지면 local minimum가 아니라 평평한 골짜기 |
| ⑤ 메커니즘 | 대표 파워(up·down branch)에서 과정별 flux fraction | fraction이 전 범위에서 1 % 미만인 과정의 계수는 데이터로 정할 수 없다(자동 경고) |
| ⑥ residual | 파워별 residual, 정규 Q-Q | 같은 부호 무리 = 모양 차이, Q-Q 기울기 > 1 = 잡음 과소 또는 모델 부족 |
| ⑦ 예측값 | 흡수 속도 σ·φ(I_ref)(intensity 환산 무관), 전달 fraction η(저여기), threshold·최대 기울기, 2·I_th population — 프로파일 앙상블 95 % 범위 | 매개변수가 non-identifiable이어도 이 양은 좁은 경우가 많다. 보고는 σ 대신 nominal intensity 기준 속도로 |

**모델 적합성 A1–A6** — 모두 같은 파워·시간에서 실측 대 DRE 모델 비교다(INNO Prism SegPA 의 s·I_th 추정과 무관).

|---|---|---|
| A1 residual 크기 | χ²/자유도 | > 5 (주의 > 2) |
| A2 residual의 계통적 구조 | S-curve별 부호 연속(runs) 시험 | z < −3 |

- '통과'는 모델이 옳다는 증명이 아니라 찾을 수 있는 구조적 모순이 없다는 뜻이다.

## XPS (읽기 · 배경 · 피팅 · 불확도 · 정량 · survey)

Avantage 를 대신해 쓸 수 있도록 만든 탭이다. 앱의 파일 열과 별개로 **자체 파일 목록**(시료별 묶음)을 쓴다. 계산은 Web Worker 에서 돌고 중단할 수 있다.
작업 상태는 브라우저(IndexedDB)에 자동 보관되고, `프로젝트 저장`(JSON)으로 옮길 수 있다. 수식의 정의는 `modules/xps/SPEC.md` 하나다.

### 읽는 파일

| 형식 | 무엇을 읽나 | 비고 |
|---|---|---|
| **Thermo `.VGD`** (Avantage 원본, OLE2) | 세기·에너지 축·hν·pass energy·dwell·scans·lens·spot·flood gun·work function·transmission 계수·원래 경로 | 가장 정보가 많다 — 가능하면 이것으로 |
| VAMAS `.vms` / `.npl` (ISO 14976) | REGULAR/IRREGULAR, 여러 블록, KE/BE 축 | CasaXPS 가 만든 VAMAS 는 dwell·scan = 1 이라 세기가 이미 CPS |
| Avantage 내보내기 `.xls` / `.xlsx` | 시트마다 한 영역(survey 포함) | BIFF8 을 직접 읽는다(외부 라이브러리 없음) |
| Avantage `.avg`, 2~3열 텍스트 `.txt/.csv/.dat/.xy` | BE 또는 KE + 세기 | 머리줄에 축 이름이 없으면 BE 로 보고 경고 |

같은 측정의 txt·xls·VAMAS 세 형식은 세기가 비트 단위로 같다(회귀 시험).

> **함정 — VGD 의 'counts' 는 순수 Poisson counts 가 아니다.** VGData 값은 정수가 아니다(검출기 채널→에너지 보간).
> 실측 분산은 dwell×scans 로 계산한 Poisson 분산의 약 절반이다(이웃 점 양의 상관). 그래서 counts 환산은 분산의 **모양**(∝ 세기)에만 쓰고,
> 절대 척도는 언제나 피팅의 χ²ν(φ)로 다시 정한다. 잔차 이웃상관 ρ₁ 은 공분산 보정 배수와 AR(1) Monte Carlo 로 반영한다.

### 시료 묶음과 대전 보정

**시료 묶음**: 대전 보정 Δ 는 시료마다 하나이고, 같은 시료의 스펙트럼끼리 자동으로 묶인다.
- VGD — 파일 안의 원래 측정 경로에서 **자료 / 실험 / 측정 조건 / 측정 지점** 네 단계(예: `K231213C / Experiment2 / X-Ray018 400um - FG ON / W1`). 목록에는 지점 이름(W1)과 그 아래 작은 글씨로 맥락이 보인다. 다른 실험의 같은 지점 이름(W1)은 따로 묶인다.
- Avantage xls — 통합문서(+ 지점) 하나. txt·VAMAS — 파일 이름에서 원소 부분을 뗀 나머지.
- 묶음이 틀렸으면: 목록의 **✎** 로 묶음 이름을 바꾸거나(다른 묶음과 같은 이름이면 합쳐짐), **정보 탭 → 시료 묶음**에서 스펙트럼 하나를 옮긴다.

**대전 보정 줄**(파일 열기 아래): `대전 보정 · 시료 이름 · 상태 · 맞추기 · 기준 설정`.
- **C 1s 로 맞추기** 한 번이면 된다 — 같은 시료의 C 1s 가 아직 피팅되지 않았으면 자동 제안 → 피팅까지 하고, 기준 성분을 기준 BE(기본 284.8 eV)에 맞춘 뒤 원래 보던 스펙트럼으로 돌아온다(알림의 `C 1s 피팅 보기`로 확인).
- 기준 성분(자동) = C 성분 중 넓이가 C 합의 10 % 이상인 것 가운데 **가장 낮은 BE**(보통 C–C/C–H; 작은 탄화물·잡음 성분은 건너뜀). C 1s 화면에서 성분을 골라 두고 누르면 그 성분을 쓴다.
- 상태: `보정 안 함`(주황 — C 1s 가 있는데 안 맞춤) · `Δ +0.16 eV — C 1s 284.64 → 284.80 eV · 파일 · 성분`(초록) · 기준 C 1s 를 다시 피팅해 기준 성분 BE 가 바뀌면 주황 `다시 맞추기`.
- **기준 설정 ▾**: 기준 스펙트럼(시료 안에 C 1s 가 여럿이면 고름) · 기준 성분 · 기준 BE(284.8 / 285.0 / Au 84.0 단추) · **선택한 성분을 기준 BE 로**(C 1s 가 없을 때 — 예: Au 4f7/2 를 84.0 eV 로) · Δ 직접 입력 · 보정 해제. 기준 C 1s 가 피팅돼 있으면 설정을 바꾸는 즉시 다시 맞춘다.
- 피팅은 측정 BE 로 하고 그래프·표·정량·survey·내보내기에만 Δ 를 더하므로 **피팅 순서와 무관**하다(넓이·FWHM·at% 는 Δ 와 무관). 결과·정량 탭에는 보정 전이면 그 사실이 맨 위에 뜬다.
- adventitious C 1s 기준은 시료 일함수에 따라 수백 meV 까지 달라질 수 있다(Greczynski & Hultman, Prog. Mater. Sci. 107, 100591, 2020) — 논문에는 기준과 값을 밝힌다.

알림은 그래프 아래 한 줄에 최근 것이 뜨고(× 로 닫기), `이전 알림`을 펼치면 앞의 것들을 다시 볼 수 있다.

### 선모양 (모두 ℝ 위 넓이 1 — 넓이가 곧 성분 세기)

- **GLS** — Gaussian–Lorentzian 합(pseudo-Voigt, Avantage 'Sum'). FWHM 이 정확히 F.
- **GLP** — 곱(Avantage 'Product', CasaXPS GL(m)). 정규화 상수는 erfcx 해석식. 0<m<1 이면 실제 FWHM ≠ F → 표에는 **수치 반치폭**.
- **V** — 진짜 Voigt(Faddeeva 함수, Weideman N=32). Gaussian 폭(장비)과 Lorentzian 폭(core-hole 수명)을 따로 읽을 수 있다.
- **DS** — Doniach–Šunjić ⊗ Gaussian(금속의 비대칭, 꼬리는 높은 BE 쪽). ℝ 적분이 발산하므로 넓이는 **피팅 영역 안 적분**.
- **LA** — 비대칭 Lorentzian 거듭제곱 ⊗ Gaussian(CasaXPS LA 와 같은 형태). **α = 높은 BE 쪽, β = 낮은 BE 쪽** 지수(작을수록 그쪽 꼬리가 길다 — 금속은 α < β, 예: Ni LA(1.1, 2.2)). CasaXPS 의 세 번째 인자(정수 Gaussian 지수) 대신 여기서는 wG(eV). α=β=1, wG=0 이면 Lorentzian.
- **GLT** — GL 합 + 지수 꼬리(Avantage tail 과 같은 목적).
- **Doublet** — 한 성분으로 두 봉우리. 간격 Δ 의 출발값은 Avantage 원소표(없으면 X-ray Data Booklet)의 두 subshell 차이고, **Δ 는 그 값 ± max(0.3 eV, 5 %, 두 출처 차 + 0.1) 안에서 자유**다(라이브러리 값은 원소 상태·인쇄 정밀도의 한계가 있어 고정하면 치우친다 — 예: Si 2p Booklet 0.40 vs 실측 ≈ 0.61 eV). 같은 원소의 두 번째 이후 doublet 은 Δ 를 첫 것에 연결. 넓이 비 = (2j+1) 비(p ½, d ⅔, f ¾), 폭 배율 q 는 **수명(Lorentzian) 폭에만**(V·DS 는 wL, GL 계열·LA 는 F) — 장비 Gaussian 폭 wG 는 두 짝에 공통. 2p½ 의 Coster–Kronig 폭 넓어짐은 q 를 풀어서.

> **정적 배경의 넓이 편향**: 끝점으로 정하는 배경(Linear·Shirley·Smart·Tougaard)은 창 밖과 끝점 평균 안으로 들어간 Lorentzian 꼬리 넓이를 잃는다(합성 시험 −2…−5 %). 꼬리가 큰 성분이면 화면에 경고가 뜬다 — 창을 넓히거나 ‘Shirley — 피팅 안에서’를 쓴다(이때 참값 회복).

> **함정 — 격자 합성곱은 매끄러워야 한다.** DS·LA·GLT 는 세밀 격자에서 합성곱한다. 격자 간격이 폭 매개변수에 따라 연속으로 변하면
> 목적함수가 계단처럼 되어 LM 이 멈추고 공분산이 80–170 % 틀렸다(기준 구현 대조로 발견). 지금은 간격을 0.04·2⁻ᵏ eV 로 양자화하고
> 마디를 성분 중심에 고정, Catmull–Rom(C¹) 보간을 쓴다. Gaussian 이 없는 LA·DS 는 격자 없이 해석식(DS 영역 정규화는 원시함수), 지수 꼬리는 2차 보간 정확 적분 —
> 기준 구현(quad)과 선모양 차 ≤ 1×10⁻⁵(최댓값 대비), 해석형 ≤ 10⁻¹⁵, 피팅 매개변수 차 ≤ 0.003σ.

### 제약 (Avantage 의 constraint 와 같은 기능)

매개변수마다 `자유(상·하한)` · `고정` · `연결`. 연결은 **BE: 기준 성분 + b eV**, **넓이·폭·모양: 기준 성분 × k**. 사슬 연결 가능, 순환은 막는다.
넓이 ≥ 0 은 항상. 한계는 MINUIT 식 변환(양쪽: sin, 한쪽: √)으로 무제약화해 LM 이 경계에서 멈추지 않게 한다.

### 피팅

- **목적함수**: χ² = Σ(y−μ)²/v, v = 준-Poisson(1차: 평활 데이터, 수렴 뒤 v = μ 로 한 번 더 — IRLS 2회).
- **최적화**: Levenberg–Marquardt(Nielsen 감쇠). 넓이 초기값은 비선형 매개변수를 고정한 가중 NNLS.
- **다중 시작**: 비선형 자유 매개변수를 한계 안 Latin hypercube 로 N 개(기본 24) → 최소 χ². 같은 최솟값(Δχ²<1)에 온 비율을 '해 유일성'으로 보인다.
  이 비율이 낮으면 해가 여러 개라는 뜻이다 — 제약을 더하거나 성분 수를 줄일 것.
- **적합도**: χ²ν, R², 잔차 RMS/σ, Durbin–Watson, ρ₁, runs z, AICc·BIC(같은 데이터·같은 분산 모형끼리만 비교).
  `모형 비교에 저장`으로 여러 모형을 남기고 결과 탭에서 AICc·BIC 로 비교한다. AICc·BIC 는 **데이터만으로 정한 분산**(평활 데이터)으로 계산한 χ² 를 쓴다 — 2차 분산 v = μ 는 모형마다 달라 모형 비교에 섞이면 안 되기 때문.
- **시작점 선택도 같은 이유로 1차 χ²** 로 한다(시작점마다 2차 가중이 다르다). 이 결함은 두 번째 기준 구현과 대조하다 발견해 고쳤다.

### 불확도

- **공분산** C = (JᵀV⁻¹J)⁻¹·φ. 한계에 닿은 매개변수는 빼고(표시), BE·넓이·넓이 %·FWHM·높이는 델타 방법으로.
- **Monte Carlo**: 최적 μ 에 AR(1) 잡음(분산 φ·v, 상관 ρ₁)을 더한 합성 데이터를 다시 피팅 → 표준편차와 2.5–97.5 % 구간. 연결·한계·비선형성을 모두 반영하므로 보고용은 이것.
- **검증(참값을 아는 합성 데이터 120 개 × 3 성분, 참 배경 모형)**: 95 % 구간 적중률 BE 95.0 %, 넓이 95.8 %, FWHM 93.6 % — 공분산 σ 가 과소·과대평가되지 않음.

### 정량

at%ᵢ = 100·(Aᵢ/(Sᵢ·T(KE)·λ(KE))) / Σ. 원소마다 한 선만 체크한다(예: Co 2p 와 Co 3p 중 하나).

- **S (감도계수)**: Scofield 1976(Al/Mg Kα, C 1s = 1) · Avantage **ALTHERMO1** · 직접 입력.
- **T (transmission)**: VGD 파일의 계수(같은 장비의 VGD 를 하나 열어 '장비 함수를 이 프로젝트 기본으로' 하면 xls·txt 에도 적용) · (PE/KE)ˣ · 없음.
- **λ (IMFP)**: KEⁿ(기본 n = 0.6, Avantage 의 energy compensation 과 같은 꼴) · TPP-2M(밀도·가전자 수·분자량·band gap 입력) · 없음.
- 불확도: 넓이 σ(피팅 공분산 또는 MC) → at% 델타 방법. 감도계수·T·λ 의 계통 오차는 들어 있지 않다.

> **함정 — Avantage at% 와 맞추려면 짝을 맞춰야 한다.** ALTHERMO1 은 Scofield 와 다르고(예: Ta 4f 9.09 vs 8.62),
> Avantage 의 transmission·energy compensation 과 **짝**으로 만들어진 값이다. ALTHERMO1 + VGD transmission + KE^0.6 이 Avantage 설정에 가장 가깝다.
> VGD transmission 계수의 함수 꼴(ln T = Σaₖ(ln(KE/PE))ᵏ)은 추정이다 — KE 에 따라 단조 감소(CAE 물리와 일치)는 확인했지만 Avantage 숫자와의 대조는 아직이다.

### Survey 원소 판별

봉우리 찾기 → **가장 큰 미설명 봉우리부터** 그 봉우리를 '센 선'으로 설명하면서 다른 선들도 같은 화학 이동 δ(−4…+6 eV)로 맞는 원소를 채택한다(수작업 판별 순서).
위치는 Avantage 원소표, 가중은 Scofield. 결과: 채택(기본 체크) · 가능·겹침(점수는 높지만 주된 선이 다른 원소와 겹침) · 겹침 · 미배정 봉우리 목록.
채택한 원소로 survey 반정량(주선 창 적분)도 낸다 — 겹침·위성을 고려하지 않는 대략값.

- **검증(합성 survey 150 개, 참값 원소 3–8 개, 문턱 4)**: 검출 가능한 원소(주선 SNR > 15) 채택 97.2 %, 없는 원소 오채택 0.05 개/스펙트럼(정밀도 98.7 %).
  봉우리 높이는 지형 prominence, 잡음은 평활 뒤 σ 로 잰다 — 이전 방식(국소 기준선·평활 전 σ)은 큰 봉우리 꼬리의 잡음 굴곡을 봉우리로 잡아 오채택이 0.59 개였다.
- 실측 BCT survey: Ba·O·Ta·C 채택, Co 는 '가능·겹침'(Co 2p 가 Ba 3d 와 겹친다) — 영역 스펙트럼으로 확인하는 것이 맞다.
  BCT xls survey 는 117.1 eV 봉우리 하나(SNR 8)로 Al 을 채택한다(Al 2s 위치, Al 2p 는 안 보임) — 같은 시료의 VGD survey 에서는 SNR 5 로 채택되지 않는다. Al 2p 영역 스캔으로 확인하기 전에는 판단 보류.

### 어떤 원소든 — 원소·궤도 지정과 자동 제안

탭의 계산 규칙에는 특정 원소·조성에 맞춘 것이 없다. 원소마다 다른 것은 라이브러리(위치·doublet Δ·넓이 비·Scofield·ALTHERMO1)에서만 온다.

- **원소·궤도**: 파일 이름에서 읽는다(`Fe2p`, `Fe 2p Scan`, `fe2p`, `[S-1] Fe2p.txt`, `Fe_2p` 모두 — 주기율표 기호로 검사). 못 읽거나(`Peak3` 등) 틀리면 **정보 탭 → 원소·궤도 → 적용**. 이 값이 doublet·참고선·감도계수를 정한다.
- **광원**: hν 1486.6 ± 3 eV 는 Al Kα, 1253.6 ± 3 eV 는 Mg Kα 의 Scofield. 그 밖(단색 Ag 등)은 감도계수를 직접 넣으라고 경고한다.
- **자동 제안**(두 단계): ① 봉우리 찾기(가장 큰 것의 2 % 이상) → doublet 짝 맞추기 → 출발 모형(Δ·m 의 연결 기준 = 가장 큰 성분, BE 는 창 안) ② **잔차 보강** — 한 걸음마다 「잔차 덩어리(z ≥ 4)에 성분 추가」, 「doublet 넓이 비 r 풀기」, 「폭 배율 q 풀기」를 모두 맞춰 보고 BIC 를 가장 많이 줄이는 하나를(10 이상일 때만) 받는다. 넓이가 0 으로 가거나 창 밖으로 나간 성분은 뺀다. r·q 는 모든 화학 상태에 같은 값 — 통계 비 (2j+1) 는 Ba 4d 같은 얕은 준위에서 자주 어긋난다(실측 K2312 Ba 4d: 0.667 → 0.69). 판단은 늘 ‘Shirley — 피팅 안에서 + 기울기’ 배경으로 한다(정적 배경으로 판단하면 배경 모양 오차가 가짜 성분이 된다). 결과는 **출발값**으로만 성분 표에 들어가고, 피팅은 사용자가 누른다. 무엇을 더하고 뺐는지는 알림에 나온다.
- **검증**(`test/all_elements.js`): Li–U 에서 제외 원소를 뺀 모든 원소의 센 궤도 2 개(BE 10–1300 eV) **143 경우**, 참값을 아는 합성 스펙트럼.
  이름 해석 5 형식 × 143 모두 · Scofield(Al) 모두 · 단일 화학 상태: 자동 제안 → 피팅으로 BE ±0.06 eV · 넓이 z < 4.5 · Δ ±0.15 eV **143/143** ·
  잔차 보강이 가짜 성분을 더한 경우 **0/143** · 화학 상태 2 개(2.5 eV 차, 2:1)를 자동 제안 + 잔차 보강만으로 성분 수·BE·넓이(±10 %) 회복 **143/143** ·
  참이 통계 비인데 r·q 를 푼 경우 **0/143** · 참 r 이 통계 값의 1.2 배일 때 r 을 풀어 ±5 % 회복 **104/105**(Au 4f 는 두 상태의 4f5/2·4f7/2 가 겹쳐 r·q 가 함께 움직임).
- **결함(10-16, 실측 Ba 4d 로 발견)**: 0.7 % 높이의 작은 봉우리(83 eV)가 첫 doublet 이 되어 Δ·m 연결 기준이 됐고, 피팅이 그것을 창 밖(76 eV)·넓이 0 으로 보냈는데 다른 성분이 연결로 참조해 빼지도 못했다 → 기준 = 가장 큰 성분, BE 창 안 제한, 기준을 빼면 다음으로 큰 성분이 물려받음.
  이전 버전에서 자동 제안한 모형이 저장돼 있으면 **자동 제안을 다시 누르면** 된다.
- 자동 제안은 **다중항·위성이 없는 스펙트럼**에서 검증했다. Co²⁺/Ni²⁺ 다중항, shake-up 위성, plasmon 이 있는 스펙트럼(예: 실측 BCT Co 2p, χ²ν ≈ 150)은 출발점일 뿐이고 모형을 직접 짜야 한다.

### 다중항 준위 (3d 전이금속 3s·3p, 희토류 4d 등)

Ti–Cu 의 3s·3p 와 Ce–Yb 의 4s·4p·4d·5s·5p 는 열린 껍질(3d·4f)과의 교환 상호작용으로 넓게 갈라져 **doublet 모형이 맞지 않는다**.
이 준위에서 자동 제안은 doublet 없이 넓은 성분 몇 개로 모양만 맞추고, 피팅·결과 탭에 안내가 뜬다 — **성분 하나하나를 화학 상태로 해석하지 말고 넓이 합을 정량에** 쓴다.
화학 상태는 같은 조건의 표준 시료 스펙트럼 모양과 비교한다(템플릿 저장 활용). 닫힌 껍질 상태(Ti⁴⁺ 3d⁰, Cu⁺·Cu⁰ 3d¹⁰, Yb²⁺ 4f¹⁴)는 일반 doublet 으로 맞출 수 있다 — 직접 doublet 을 켜면 경고만 뜬다.
예: K2312 Co 3p — doublet 모형은 Δ 가 한계(2.1 eV)에 붙고 χ²ν 2.7·ρ₁ 0.78, 다중항 처리 뒤 χ²ν 0.68·ρ₁ 0.11.

### 모형 민감도 (결과 탭) — 피팅의 주관을 숫자로

겹친 봉우리를 성분으로 나눈 값(예: 상태별 넓이 %)은 측정값이 아니라 모형의 결과라, 배경 종류·창 끝 같은 분석자의 선택에 따라 달라진다. 이 기능은 **성분 구성은 그대로 두고 그 선택들만 바꿔 다시 맞춰** 값이 얼마나 흔들리는지 보인다.
- 피팅한 뒤 결과 탭 → **분석 선택 흔들어 보기**. 방식: 빠르게(한 번에 하나씩, 약 9 회) · 꼼꼼히(모든 조합, 약 45 회). 배경 후보·창 끝 ±(기본 0.5 eV)·끝점 점 수를 고를 수 있다.
- 표: 넓이 % 기준 ± 통계 σ · 분석 선택 범위(최소–최대) · **가능 범위 = [최소 − 2σ, 최대 + 2σ]** · 변형별 값 점 띠 · 가장 큰 영향을 준 선택 · BE·FWHM 범위. 아래에 **보고 예** 문장.
- 배지: **분석 선택이 지배**(흔들림의 반이 통계 2σ 보다 큼 — 배경·창 선택을 보고에 꼭 밝힐 것) / 통계가 지배.
- 통계 σ = 공분산 σ × 잔차 이웃상관 보정(Monte Carlo 를 돌렸으면 그 sd 와 큰 쪽).
- 합성 시험(40 회, 참 배경이 후보 중에 있을 때): 배경을 틀리게 골랐으면 통계 ±2σ 만으로는 참값을 12 % 만 포함, 가능 범위는 93 %(95 % 신뢰구간 약 80–97 %). 배경이 맞으면 둘 다 95 % 이상. **참 배경이 후보 밖이면 보장되지 않는다.**
- 지금 배경은 항상 기준(0 번)으로 들어가고, 사용자가 건 배경 제약(예: 기울기 고정)도 그대로 쓴다.
- 이 기능이 재지 않는 것: **성분 수·모양 자체의 선택**(그건 '모형 비교에 저장' + BIC 로), 감도계수의 계통 오차.

### 화학량론 비교 (정량 탭 아래)

화학식을 넣으면(예: `NaLuF4`, `Na(Lu0.92Tm0.08)F4`, `Na3LuCl6` — 괄호·소수 가능) 정량 표에서 체크한 원소 중 **화학식에 있는 원소끼리만 다시 정규화**해
측정 % · 화학식 % · 측정/화학식 · 기준 원소에 대한 비(기본 = 가장 무거운 원소, 바꿀 수 있음)를 보인다. C·O 같은 화학식 밖 원소는 비교에서 빠지고(정량 표에는 그대로), 측정 안 된 화학식 원소도 따로 알린다.
- σ 는 넓이 불확도만(델타 방법, Monte Carlo 와 0.9 % 일치). **감도계수 오차만으로도 흔히 ±10–20 %** 라 1 에서 조금 벗어난 것은 조성 차이가 아닐 수 있다 — 같은 조건의 표준 시료로 감도계수를 맞추면 가장 확실.
- 선들의 운동에너지가 크게 다르면(KE 비 > 1.8) **보는 깊이가 다르다**는 경고가 뜬다. 깊이 칸: TPP-2M 이면 3λ(nm), KE^n 이면 기준 원소 대비 λ 비. 같은 원소의 KE 가 다른 두 선(예: Na 1s ↔ Na 2s)을 비교하면 표면 농축과 조성을 구분할 수 있다.
- 화학식은 시료마다 저장된다.

### Auger parameter α′ (Auger α′ 탭)

α′ = BE(광전자선) + KE(Auger 선). 두 선이 대전으로 같은 만큼 움직여 **대전 보정과 무관** — 대전이 큰 절연체(플루오라이드·클로라이드 나노입자 등)에서 화학 환경을 비교하는 데 쓴다.
- **자동 짝짓기**: 시료 안의 Auger 영역(파일 이름에 `Na KLL`, `F KLL`, `Cu LMM` 등)마다 같은 원소의 광전자 영역을 짝짓는다. 피팅된 성분이 있으면 가장 큰 성분, 없으면 구간 최댓값.
- **직접 추가**: 광전자선·Auger 선의 스펙트럼과 위치(성분 또는 구간 최댓값)를 고른다. survey 를 고르면 라이브러리 Auger 위치 ±6 eV 구간이 자동으로 들어간다.
- σ 는 두 쪽 모두 피팅된 성분일 때만(공분산). 최댓값 방식은 잡음에 따라 약 0.1 eV 흔들린다(합성 시험) — 보고용은 성분 피팅으로.
- **Wagner plot**: 가로 BE(대전 보정, 오른쪽으로 감소) · 세로 KE, 같은 eV 눈금이라 α′ 일정선이 45°. 이 프로젝트의 모든 시료 점 + 사용자가 넣은 기준점(문헌·표준 시료; 출처를 이름에 적기). 앱은 문헌 α′ 표를 싣지 않는다(검증된 자료가 없어서).
- 주의: Avantage xls·텍스트는 hν 가 파일에 없어 기본값을 쓴다 — 실제 광원과 다르면 α′ 가 그만큼 틀린다(화면 경고). VGD 는 파일의 hν.

## Image Analysis (ImageJ 방식 이미지 분석)

ImageJ 의 주요 기능을 옮긴 탭이다. 기존 '이미지' 탭(STEM·EDS 뷰어)과 별개로 자체 이미지 목록을 가진다.
계산은 ImageJ 1.54u 소스의 알고리즘을 그대로 옮겨, 같은 입력에서 ImageJ 와 같은 결과를 낸다(검증: ImageJ 실행 결과 275 사례와 화소·수치 대조).

### 화면
- **왼쪽**: 열린 이미지 목록(썸네일, 크기·형식·화소 크기). 처리로 새로 생긴 이미지(mask·projection·FFT)는 원본 아래 들여쓰기.
- **가운데**: 도구 막대(Rectangle·Oval·Polygon·Freehand·Line·Angle·Multi-point·Wand·Set Scale·Scroll·Zoom), 이미지, 스택 막대(c/z/t, Play), 상태 줄(좌표·보정 좌표·화소 값·ROI 크기), 선 ROI 의 Line profile.
- **오른쪽 패널**: Adjust · Process · Threshold · Binary · Analyze · Measure · Macro · Info.
- **아래 표**: Results · Particles · Summary · Distribution · Plots. CSV 저장, 표 복사(Excel·Origin 에 붙여 넣기).

### 읽는 형식과 화소 크기
**Nikon ND2**(NIS-Elements v2·v3: 채널·Z·T·XY 위치, lossless, 채널 이름·색), **Leica LIF**(LAS X·LAS AF: series·tile·채널·Z·T·λ, RGB, 염료 이름), **Olympus OIR·POIR**(FluoView FV3000/FV4000: 채널·Z·T·λ, 채널 색, 참조 이미지 — 공개 실측 13 파일로 검증), **Zeiss CZI**(ZEN: 채널·Z·T·scene, mosaic tile 합성, zstd 압축, Airyscan·Lattice Lightsheet·SEM), TIFF/BigTIFF(8·16·32-bit, float, RGB, stack, tile, LZW·Deflate·PackBits, ImageJ hyperstack·OME-TIFF), PNG(16-bit 그대로), JPEG·BMP·GIF·WebP, DM3/DM4, MRC, Velox EMD, Bruker BCF, **AFM**: Gwyddion GWY·GSF(채널·mask·volume), Bruker Nanoscope(.spm·.000–.999·.pfc, 채널·Trace/Retrace), Asylum ARDF(force map 의 이미지 채널), Igor IBW(Asylum Cypher·MFP-3D, 채널별 — 높이 nm·위상 deg·KPFM 전위 V·C-AFM 전류 pA/nA·주파수 Hz), Nanonis SXM(채널·fwd/bwd), NumPy NPY, 텍스트 행렬, Raw(크기·형식 지정).

화소 크기는 출처가 확실한 메타데이터만 자동으로 쓴다: ND2 `dCalibration`, CZI `Scaling`, ImageJ·OME 메타데이터, FEI/Thermo·Zeiss·TESCAN SEM 태그, Hitachi·JEOL 의 옆 `.txt`(이미지와 **같은 이름으로 함께 열기**), DM·MRC·EMD 보정, Igor wave scaling, Nanonis scan range, Gwyddion·Nanoscope·ARDF 의 주사 크기. 출처는 Adjust ▸ Set Scale 과 Info 에 적힌다.
TIFF·PNG 의 해상도 태그는 72 dpi 같은 기본값이 흔해 '후보'로만 보인다 — 맞으면 '적용'.
메타데이터가 없으면 도구 막대의 **Set Scale**(자 모양)로 이미지 안 축척 막대 위에 선을 긋고 길이를 넣는다. 'Shift' 를 누르고 그으면 수평·수직.
FEI 이미지 아래의 데이터 막대는 경고와 함께 한 번에 잘라낼 수 있다(입자 분석 전에 꼭).

**ND2·CZI**: 채널 이름과 색(LUT), z step, 대물렌즈·장비 정보가 Info 에 들어온다. XY 위치(multipoint)·scene 은 이미지가 따로 열린다.
위치·scene 이 6 개를 넘거나 32-bit 로 600 MB 를 넘는 파일은 **Import 창**에서 위치·scene 과 Z·T 범위·간격을 고른다(예: 1 GB z-stack 을 2 장마다). 한도는 1.6 GB.
읽지 않는 것: NIS-Elements 3 이전의 ND2 v1(JPEG 2000), CZI 의 JPEG XR 압축(slide scanner) — 열 때 분명히 알린다.

**AFM (GWY·Nanoscope·ARDF)**: 채널마다 이미지가 열리고 값은 물리량이다 — 높이·변형은 **nm**, 힘은 nN, modulus 는 MPa·GPa 처럼 크기에 맞게, 전압·위상은 V·deg 그대로. 마우스 아래 값에 단위가 붙고 Info 에 파일의 눈금(예 Z scale × soft scale)이 적힌다.
Gaussian·Median·회전·자르기처럼 같은 물리량을 남기는 처리는 단위를 이어받고, 8-bit 변환(눈금)·문턱·FFT·곱셈 뒤에는 단위가 지워진다.
Nanoscope 는 Gwyddion 과 같은 규칙으로 읽는다(위아래 방향 포함). 힘 곡선 파일·Force Volume 의 곡선·ARDF 의 force curve 는 읽지 않고 알린다(이미지 채널은 읽음).
ARDF 는 Asylum 이미지처럼 첫 줄이 아래이고, 주사 간격은 파일의 IDEF 값을 쓴다(직사각 주사도 맞음). 실측 ARDF 는 아직 확인하지 못했다 — 열어서 IBW·Asylum 화면과 방향·값이 다르면 알려 주세요.

### 입자 크기 분석 (SEM·TEM 나노입자)
1. **Process**: 필요하면 Subtract Background(rolling ball 반지름 > 가장 큰 입자 반지름), Median·Gaussian 으로 잡음 줄이기. **Preview** 로 결과를 미리 본다.
2. **Threshold**: 방법(Default·Otsu·Li·Triangle … 16 종)과 Dark background(밝은 입자). **Try all methods** 로 16 방법을 한눈에 비교. 빨강이 선택 영역. **Convert to Mask**.
   RGB(색) 이미지면 Threshold 패널이 **Color Threshold** 가 된다(ImageJ Image ▸ Adjust ▸ Color Threshold 와 같은 계산): 색 공간 HSB·RGB·Lab·YUV, 채널마다 min–max 와 Pass(안)/stop(밖).
   빨강처럼 Hue 0/255 를 감싸는 색은 Hue 의 Pass 를 끈다. 원하는 색 위에 ROI 를 그리고 **Sample (ROI)** 로 범위를 잡을 수 있다. **Mask 만들기** → 8-bit mask 로 4·5 단계(Redirect = 원본).
3. **Binary**: 붙은 입자는 **Watershed**(EDM 극대 기준, 볼록한 입자에 맞음). 구멍은 Fill Holes.
4. **Analyze**: size(unit² 또는 pixel), circularity, Exclude on edges, 세기를 원본에서 재려면 Redirect = 원본. **Analyze** → 번호 겹쳐 그리기, Particles 표, Summary(개수·면적 분율·평균·ECD·number density).
5. **Distribution**: 변수(ECD·Feret·Area·AR …), 칸 수(기본 Freedman–Diaconis), log x, 로그정규 곡선과 x̄g·σg, D10/D50/D90, span. '열린 모든 이미지 합치기' 로 여러 이미지의 입자를 한 분포로.

주의: Exclude on edges 를 끄면 잘린 입자가 작은 쪽으로 분포를 끈다. 입자 수가 100 개 미만이면 평균의 표준오차가 크므로 여러 이미지를 모은다(Macro ▸ Batch). Include holes 를 켜면 구멍 안의 다른 입자는 바깥 입자에 포함된다(ImageJ 와 같은 동작).

### 측정 (Measure)
ROI 를 그리고 **Ctrl+M**(ROI 없으면 이미지 전체). **T** 로 ROI Manager 에 추가, 'Measure all ROIs'. 표의 열은 Measure ▸ Set Measurements 에서 고른다.
둘레는 ROI 종류마다 ImageJ 정의를 따른다(traced: 꺾임 보정 둘레, oval: Ramanujan 근사, freehand: 3 점 평활). Multi-point 는 Type 1–8 로 나눠 세는 counter(Alt+클릭 = 지우기).

### 그 밖의 분석
- **Find Maxima**: prominence 보다 더 솟은 극대만 — 원자 열·형광 점 세기. Point selection 또는 Single points / Segmented 이미지.
- **Radial Profile**: 점·타원 ROI 중심 둘레의 방위 평균. 보정 단위가 1/nm(회절·FFT)이면 봉우리마다 d = 1/r 을 함께 보인다.
- **Orientation**: 구조 텐서(OrientationJ 정의) — 주 방향(가로축 기준 반시계 +), order parameter, 방향 색 지도(색상 = 방향, 채도 = coherency).
- **Analyze Skeleton (2D/3D)**: 나노선·섬유·결정립계·균열 망의 가지 수·접점·길이. Fiji 의 Analyze Skeleton 과 같은 숫자가 나온다(Fiji 를 실행해 고정 102 경우 + 무작위 수천 경우 대조, 가지치기 포함).
  Fiji 코드를 쓰지 않고 새로 만든 독립 구현이라 라이선스 제약이 없고, Longest shortest path 는 Fiji 의 크기 제한(꼭짓점 수천 개면 매우 느림) 없이 큰 망에서도 1 초 안팎.
  **가지치기**: Prune cycle method(고리 자르기 — shortest branch · lowest intensity voxel · lowest intensity branch, 세기 방식은 같은 크기의 원본 회색 이미지를 고름)와 Prune ends(끝 가지 제거) — Fiji 와 같은 결과.
  Threshold ▸ Convert to Mask 한 이진 이미지에서 '먼저 Skeletonize' 를 켜고 Analyze(이미 골격이면 끔). 스택은 3D 로(z 간격 = z step).
  아래 **Skeleton** 탭: 골격마다 가지·접점·끝점 수, 평균·최대 가지 길이, triple/quadruple point, Longest shortest path(가장 긴 최단 경로 — 섬유 길이 대용), 그리고 가지마다 길이·양 끝 좌표(Branch information, CSV).
  Tagged skeleton 이미지에서 끝점·줄기·접점을 색으로 확인한다. 가지 길이는 화소 중심을 잇는 거리의 합이라 짧은 가지(몇 화소)는 접점 처리에 따라 1–2 px 차이가 날 수 있다 — Fiji 와 같은 규칙.
  길이가 똑같은 최장 경로가 둘 이상이면 경로·시작점이 Fiji 와 다를 수 있어 알림이 뜬다(길이 값은 같음).
- **FFT**: power spectrum 위에 ROI 를 그리고 Inverse FFT(통과 또는 제거, 원점 대칭 자동) — 주기 잡음 제거·격자 필터.
- **Stack**: Z Project, Z-axis profile, **Register**:
  - **StackReg** 방식(TurboReg, Thévenaz 1998): Translation · Rigid Body(이동+회전) · Scaled Rotation(+배율) · Affine(+전단). 기준 = 이전 장(누적, StackReg 와 같음) · 첫 장(첫 몇 장 평균) · 평균 이미지.
  - Translation — phase correlation: 평행 이동만, 빠름.
  - 기준 채널로 변환을 구해 모든 채널에 같은 변환. z·t 가 모두 있으면 t 마다 z 최대 투영으로 구해 모든 z 에 적용(시간 drift 보정). 이동·회전·배율 그래프는 Plots 탭.

### Macro · Batch
모든 작업이 자동으로 기록된다(ImageJ Recorder 와 같은 역할). Macro 패널에서 필요 없는 단계를 지우고 순서를 바꾼 뒤
'현재 이미지에 실행', '선택한 이미지에 실행', '파일 고르고 batch 실행'(파일을 하나씩 열어 처리하고 결과는 Summary 표로; 결과 이미지 TIFF zip 선택).
문턱은 기록한 **방법**으로 이미지마다 다시 구한다(수동 범위였다면 그 값). `.json` 으로 저장·불러오기, **Export .ijm** 은 같은 처리를 ImageJ/Fiji 에서 폴더 단위로 돌리는 매크로.

### 저장
**TIFF 저장**은 ImageJ 호환(보정·stack·hyperstack 정보 포함, ImageJ 로 열어 확인함). **PNG 내보내기**는 보이는 그대로(LUT·겹쳐 그린 것·축척 막대) 원래 해상도.
작업은 브라우저(IndexedDB)에 자동 저장되어 새로 고쳐도 남는다. 저장 공간이 모자라면 알림이 뜨고 그 이미지는 다시 열어야 한다.

### ImageJ 와 다른 점
- Outline: ImageJ 1.54u 는 Black background 설정에서 물체 바깥 테두리를 만든다(내부 사본을 읽는 구조 때문). 여기서는 문서 정의대로 물체 안쪽 1 px 테두리.
- Register 의 StackReg 는 pystackreg(TurboReg C++ 이식)와 같은 계산이다 — '이전 장' 기준은 ImageJ StackReg 와 같이 이웃한 원본 장끼리 맞추고 변환을 누적한다. 기준 장(anchor)도 ImageJ 처럼 지금 보이는 장이다. 3D 연산(3D skeletonize 등)과 skeleton 가지치기는 아직 없다.
- AFM: Nanoscope 채널 이름은 NanoScope Analysis 화면 이름(예 Height Sensor), Gwyddion 은 내부 이름(ZSensor). ARDF 는 Gwyddion 과 달리 위아래를 뒤집고 IDEF 간격을 쓴다(Gwyddion 은 정사각으로 가정).
- 자세한 정의·검증: `modules/image/SPEC.md`.

## 참고 데이터 출처

X선 방출선 에너지: **Elam, Ravel & Sieber, Radiat. Phys. Chem. 63 (2002) 121**
(xraydb 배포판). 0.08–40 keV, 89개 원소.

상대세기는 배포판 값이 **복사 전이율**이라 그대로 쓸 수 없어 발생 부껍질별 이온화 계수를
곱해 보정했다.

```
L3 (Lα1, Lα2, Ll)          × 1.00
L2 (Lβ1, Lγ1, Lη)          × 0.56
L1 (Lβ3, Lβ4, Lγ2, Lγ3)    × 0.09
M5 (Mα)                    × 1.00
M4 (Mβ)                    × 0.60
M3 (Mγ)                    × 0.08
```

보정 후 문헌값(La 기준 Lβ1 0.65 / Lβ3 0.06 / Lβ4 0.04)이 재현된다. K 계열은 보정이
필요 없었다(Kα2/Kα1 = 0.51, ΣKβ/ΣKα = 0.146 — 둘 다 문헌과 일치).

HDF5 리더: **NIST h5wasm**.
Bruker SFS 컨테이너 형식: **HyperSpy / RosettaSciIO** 의 bruker 리더(GPL, Petras Jokubauskas)를 참고.
라이선스 고지는 HTML 안에 포함되어 있다.

XPS 원소 자료(`modules/xps/build/build_lib.py` 가 만들고, 어긋나면 빌드 중단):
- **핵심 준위 BE**: G.P. Williams, X-ray Data Booklet Table 1-1 (LBNL; Bearden & Burr 1967, Cardona & Ley 1978, Fuggle & Mårtensson 1980). 원소 상태, 금속은 Fermi 준위 기준. 인쇄값의 순서 역전(Co 3p, Na 2p)은 표시하고 doublet 간격에 쓰지 않는다.
- **감도계수**: J.H. Scofield, J. Electron Spectrosc. Relat. Phenom. 8, 129 (1976) — 디지털 표를 논문 판독값 263 개와 대조(1 %), 빠진 subshell 31 개 보충, 1 개 교정, doublet 합은 두 subshell 합으로 재계산. Avantage ALTHERMO1 함께.
- **survey 판별 위치·Auger KE**: Avantage 원소표(KherveFitting 이 디지털화한 수치만 사용). Auger KE 는 NIST SRD 20 / ASTM E2108 값과 대조.
- **IMFP**: S. Tanuma, C.J. Powell, D.R. Penn, Surf. Interface Anal. 21, 165 (1994) (TPP-2M).

## 현재 한계

- **Bruker `.bcf` 의 하이퍼맵은 아직 읽지 않는다.** `SpectrumData0` 는 존재 여부만
  표시하고, 화면의 스펙트럼은 그 전체 합이다. Velox `.emd` 의 스트림은 디코드한다.
- **원본 화소 맵은 통계가 성립하지 않는다.** 픽셀당 유효 카운트가 Velox SI 0.85–2.3,
  Bruker 0.2 수준이다. 비닝이 필요하다.
- **흡수·형광 보정 없음.** 정량은 박막 근사다. 두꺼운 시편이나 저에너지 선(O, F)에서는
  계통 오차가 남는다.
- **K 계열이 200 eV 이내로 붙은 쌍**(Cu/Ni 등)은 분리가 나쁘다.
- **0.45 keV 아래에서 SNIP 배경이 아직 20–50% 낮게 잡힌다.** 연속선이 그 구간에서 넓은
  극대를 가지는데 SNIP 은 그것을 봉우리로 보고 깎는다(SNIP 의 구조적 한계). 100만 카운트
  이상에서 N 오탐으로 나타난다. 10만 카운트 수준에서는 나타나지 않는다.
- **저에너지 꼬리의 모양은 이 장비에서 잰 값으로 고정되어 있다.** 크기(τ)만 스펙트럼마다
  맞춘다. 다른 검출기에서는 에너지 의존 지수(2.93)와 감쇠 길이(0.90σ)가 다를 수 있다.
- **C Kα 의 꼬리 비율은 상한(0.85)에 붙는다.** 277 eV 는 검출 하한(120 eV)에 가까워
  꼬리가 잘리므로 이 값은 하한으로만 읽어야 한다.
- **Energy Diagram 의 준위값은 LaF₃ 기준이다.**
  - 호스트별 결정장 이동은 넣지 않았다.
  - Ln²⁺ 의 5d 밴드와 dⁿ 이온의 Dq·B·C 는 호스트 값을 입력해야 정확하다.
  - Ce³⁺ 5d(LaF₃) 기본값은 1차 출처를 확인하지 못한 근사값이다.
  - 에너지 전달 판정은 에너지 정합성만 본다. 속도는 보지 않는다.
- **DRE 는 mean-field 모델이다.**
  - 고농도·얇은 셸·수 µs 이하 감쇠 모양에서는 이온별 미시 모델과 차이가 날 수 있다(Villanueva-Delgado 2016; Teitelboim 2019).
  - 열 효과(온도 ODE)는 아직 넣지 않았다.
- **XPS**
  - VGD transmission 계수의 함수 꼴은 추정이다(Avantage at% 와 같은 데이터로 대조 필요 — Avantage 의 Peak Table 내보내기가 있으면 확인할 수 있다).
  - Mg Kα Scofield 표에 빈칸 15 개(S 2p·2s, Ni 2p, Ga 2p·2s, Ge 2p, La·Ce·Pr·Nd 3p, Pr·Nd·Gd·Tb·Dy 3d — Mg Kα 로 들뜨지 않거나 표에 없음) — Mg 광원이면 직접 입력. Al·Mg 아닌 광원은 감도계수 전부 직접 입력.
  - 다중항 준위(3d 전이금속 3s·3p, Ce–Yb 4s·4p·4d·5s·5p)는 envelope(넓이)만 — 화학 상태 분해는 표준 시료 비교로.
  - 정적 배경(Shirley·Smart)의 넓이 오차는 창 폭에 따라 커진다(합성 143 경우: ≤ 20 eV 최대 3 %, 20–40 eV 최대 8 %, > 40 eV 최대 14 %; 20 eV 넘으면 화면 경고) — 넓은 창은 ‘Shirley — 피팅 안에서’를 권한다.
  - 서베이 판별은 후보 제시다. 겹침·위성·손실 봉우리는 자동으로 풀지 않는다.
  - 다중항 분리(Co²⁺ 등)·shake-up 위성 모형은 성분을 사용자가 구성해야 한다(Gupta–Sen 같은 미리 만든 묶음은 없음).
  - 깊이 분석(depth profile)·각도 분해·mapping 은 아직 없다.
