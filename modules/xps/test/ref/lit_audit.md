# XPS module: audit of literature-derived values (read-only, 2026-10-31)

Scope: `src/xps_lib.js` (generated from `data/` by `build/build_lib.py`), `xps_core.js`, `xps_guide.js`, `xps_io.js`, `xps_arxps.js`, `xps_proc.js`, `xps_ui.js` (defaults only), `SPEC*.md`.
No source file was changed. "Line" means an approximate line number. In the Src column, P = primary source cited, S = secondary or derived (vendor table, digitisation, SI, arXiv, citation of a citation), N = no source cited.
Impact: H = changes at% or the chemical-state assignment directly; M = changes constraints, defaults or areas in some workflows; L = display, hint or identification only.
Bibliographic details marked "?" are not certain and must be confirmed. No DOI is given unless it already appears in the code (marked "code") or I am confident of it.

## 2. Ce 3d recipe values as they stand in the code (`xps_guide.js` `RECIPES[0]`)

Window 875–925 eV (charge-corrected, C 1s C–C = 284.8). Background: in-fit Shirley + slope (`active`, n = 5). Shape GLS, m start 0.3, range 0–1, shared.
ΔE (v→u) start **18.5**, free in **18.1–18.9**, shared by all pairs. u/v area **r = 2/3**, fixed. Equal widths (q = 1, fixed). BE tolerance ±**0.6** eV. Alignment search ±**3** eV in 0.05 eV steps.

| v | v/u | Ce⁴⁺ | 882.4 | 2.3 | 1.2–3.5 |
| v1 | v′/u′ | Ce³⁺ | 885.0 | 3.1 | 1.5–4.5 |

- Implied u lines (BE + 18.5): u0 899.0, u 900.9, u′ 903.5, u″ 907.4, **u‴ 916.7**.
- Options: CeO₂ only = v, v″, v‴ (6 lines); Ce³⁺ only = v0, v′ (4); Mixed = 10 lines.
- Derived: Ce³⁺ fraction = (v0 + u0 + v′ + u′) / all 10. u‴ fraction = A(v‴ pair)·r/(1 + r) / all.
- u‴ claims: "u‴ (≈ 916.7 eV) has no Ce³⁺ counterpart" and is an internal charge reference (attributed to Isaacs 2023). SPEC says "pure CeO₂ u‴ ≈ 12–14 %", attributed to Shyu 1988 and Romeo 1993: **marked unverified in SPEC**. The verified figure is from the ACS SI only: u‴ = 11.8 % of the Ce⁴⁺ area, 9.2 % of the total, in a 78 % Ce⁴⁺ film.
- Literature columns that SPEC claims for the positions (v0, v, v′, v″, v‴, u‴):
  - Morgan 2023: 880.7, 882.5, 885.6, 889.2, 898.3, 917.0
  - "Bêche-type" (via arXiv:2010.07939): 880.6, 882.4, 884.5, 888.8, 898.2, 916.7
  - ACS SI jp1007279 Table SI-1: 880.2, 882.2, 884.7, 888.7, 898.1, 916.4
  - ΔE sources: Morgan CeO₂ 18.6–18.7 and Ce₂O₃ 18.3–18.5; Maslakov 18.3 and 18.6; ACS SI 18.3–18.5.
- Synthetic-test state shares (`test/test_guide.js` ~163, from the ACS SI): Ce⁴⁺ v 0.296, v″ 0.405, v‴ 0.299; Ce³⁺ v0 0.288, v′ 0.712.
- Conflicts and weak points:
  - The general `doubletInfo` gives Ce 3d ΔE = **18.0** (rounded Avantage positions 882/900), while the recipe uses 18.5 and the Booklet 18.6. A non-recipe Ce 3d fit gets "Fix Δ at 18.00 eV" from Fit check.
  - SPEC states that Morgan's v′/u′ label = this module's v0/u0. Check this label mapping in the original paper.
  - The width ranges (Flo/Fhi) have no cited source, yet the UI calls them "the literature span".
