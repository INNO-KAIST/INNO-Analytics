## 1. CasaXPS 피팅 규약 (`weight: "casa"`, `bg: {type:"linear", conv:"casa", aw:1}`)
- 맞추는 채널 = **i0+1 … i1−1** (영역 Start/End 채널 자체는 뺀다) → DoF = (i1 − i0 − 1) − p = 341 − 3 = **338** (판독 338 과 같음).
- **가중 없는 최소제곱** (Poisson 가중 아님). 근거: LA(1,1,0) 위치 285.000402 (판독 285.0004; 1/d 가중이면 285.000897, F 0.9537 — 크게 어긋남).
- 화면 **'RMS' = √Σ(y − μ)²** (채널 i0+1 … i1−1; DoF 로 나누지 않음). LA(1,1,0) 865.86 vs 864.459, SGL 네 판독 0.04–0.17 % 안.
  Fairley SI Eq. 1 의 'Residual STD' = √(Σ((d−e)/√d)²/n) 와는 다른 수다.
- 배경은 §2b Linear(끝점 = 채널 i0+1, i1−1 중심 ±Av.Width 평균) 고정. V2 여섯 자료의 영역 Area·Max·Min 판독을 화면 자리수까지 재현(scratch 확인).
- 엔진: `makeProblem(..., {weight:"casa"})` → `casaVar`(끝 두 채널 분산 1e30, 나머지 1, IRLS 없음); `fitStats().casa = {rms, dof, n}`; 공분산 DoF 도 N−2−k.
  기본(`poisson`/`const`) 경로는 바뀌지 않음.

### 2.1 SGL(p) — 정함
**SGL(p) = (1 − p/100)·exp(−4ln2 x²/F²) + (p/100)/(1 + 4x²/F²)** (높이 혼합, Gaussian·Lorentzian 같은 F), CasaXPS fwhm = F (= 이 함수의 실제 FWHM).
앞선 '맞지 않음' 판정(SPEC §13)은 영역 끝에서 잘리는 Lorentzian 꼬리(선형 배경이 꼬리 위에 걸림)를 피팅에서 흉내내지 않고 비교했기 때문이다 —
같은 모양이라도 이 영역에서는 RMS 442(높이 혼합 자료)·883(GLS 자료)이 남고, CasaXPS 판독이 바로 그 값이다.
채택 기준(넓이 ≤ 0.1 %, fwhm 상대 ≤ 1e-3)을 네 판독 모두 만족(최대 9.6e-4, 3.9e-4), RMS 도 0.2 % 안.
같은 F 의 높이 혼합은 넓이 혼합 GLS(F, m) 와 **같은 함수**이므로 새 모양은 만들지 않았다:
`m = sglToGLS(p) = h·A_L/(h·A_L + (1−h)·A_G)`, h = p/100, A_L = π/2, A_G = √(π/(4 ln2)); 역 `glsToSGL(m)`. (SGL(30) ↔ m 0.3874; GLS m 0.3 ↔ SGL(22.51) — SPEC §13 의 '19.5' 는 계산 오류.)
인쇄형(매뉴얼 p. 301: 안쪽 매개변수 1, m)은 맞지 않는다(그 자료도 높이 혼합 정의로 맞춤).
남은 −6e-4…−1e-3 넓이 차이는 Lorentzian 이 섞인 모든 모양에서 보이는 CasaXPS 쪽 수치 차이로 본다(§4).

### 2.2 LA 폭 숫자 — 대칭은 정함, 비대칭은 미확인
- α = β 일 때 CasaXPS 'fwhm' = **모양의 실제 FWHM** (LA(1,1,0): F 자체; LA(2,2,0): F·√(√2−1)). 차이 4–6e-4 (GL(30) 의 1.7e-4 와 같은 방향 — CasaXPS 의 수치 FWHM 측정으로 봄).
- α ≠ β (LA(1.53,2.43,0)): CasaXPS 숫자 / 피팅 F = 0.58010 (F 1), 0.57987 (F 2). 실제 FWHM(0.6657 F)도, F 도, 낮은 BE 쪽 반폭 ×2(0.5745 F)도,
  √(2^{1/p}−1) 의 p = α, β, (α+β)/2, √αβ, 조화평균도 아니다(필요한 p ≈ 2.39). 절대 에너지에 따라 비가 조금 바뀌므로(0.58010 → 0.57987) 격자 위 수치 측정이 섞인 값으로 보인다.
  → `compToCasa` 는 비대칭 LA 의 fwhm 을 `null`·`exact:false` 로 내고, `casaToComp` 는 CasaXPS 숫자를 실제 FWHM 으로 보고 F 를 정한 뒤 '다시 맞추라' 고 표시.
- GL(30)T(2) 도 같은 현상: 모양·넓이·위치·F(1.2)는 맞는데 CasaXPS fwhm 1.18051 = 0.98376 F (GL(30) 부분의 실제 FWHM 0.96136 F, 전체 실제 FWHM 1.11777 F 둘 다 아님).
  비대칭 모양에서 CasaXPS 가 보이는 '폭' 의 정의는 미확인으로 둔다.

- **α ≠ 1 에서 n 의 규칙은 측정되지 않았다** (V2 는 α = β = 1 에서만 n > 0). 같은 규칙(F_L = LA 의 F)을 가정하고 `exact:false` 로 표시.
- 엔진: 성분에 `casaN`(n)을 두면 `shapeParams` 가 w_G = n·`CASA_LA_RHO`·F 로 계산하고 wG 는 자유 매개변수에서 빠진다(F 와 함께 움직임). `casaN` 없으면 이전과 같음.

### 2.4 비대칭 지수 (asymmetry index) — 미확인
판독 0.2275 (LA(1.53,2.43,0), F 1·2 같음 → 척도 불변), 0.2138 (GL(30)T(2)). 시험한 정의 — 반높이 h ∈ {0.05…0.9} 에서 (r−l)/(r+l)·1 − l/r,
양쪽 넓이 (A_hi−A_lo)/(A_hi+A_lo)·1 − A_lo/A_hi (ℝ, 영역, ±w·FWHM 창), (평균−위치)/FWHM, (중앙값−위치)/FWHM — 어느 것도 두 값을 같이 내지 못함
(예: 1 − l/r 는 LA 에서 h ≈ 0.65, GL·T 에서는 0.2138 에 닿지 않음; 넓이 기준 1 − A_lo/A_hi 는 w ≈ 1.2 와 0.95 로 서로 다름). 구현하지 않음.

## 3. 배경 표기 — Tougaard U3 / U2
- **주의(2차 판독, 10-28):** 같은 세션에서 BG Type 을 U 2/U 3 Tougaard 로 바꾸거나 Cross Section 칸에 "1000,551,436,0"·"2866,1643,1,0" 을 넣어도 영역 Area/Max/Min 이 Linear 값에서 **전혀 바뀌지 않았다** → 영역 표가 입력 칸만으로는 Tougaard 배경을 다시 계산하지 않는 것으로 보인다. 따라서 아래 "B = 0 ⇒ Linear" 는 **확인되지 않은 해석**이며, CasaXPS Tougaard 대조 전체를 미검증으로 둔다.
- CasaXPS 는 Tougaard 매개변수를 영역의 **Cross Section 칸에 "B, C, D, T0"** 로 둔다. 'U 3 Tougaard' 를 고르면 **"0, 551, 436, 3"** 이 채워지고 **B = 0 이라 자동 척도가 없다**
  → 배경 = Linear (C1s 영역 Area 39564.8 / Max 14451.9 / Min −482.0 = Linear 판독과 같음). (SPEC §13 의 "U3: B 자동" 서술은 2.3.27 화면과 다르다.)
- `casaBg(name, cross, aw)`: `Linear`/`Shirley` → `{type, conv:"casa", aw}`; `U 2|3 Tougaard` + B = 0(또는 칸이 비면 U 3 기본값) → **Linear(conv casa)**, `exact:false`(미검증),
  원래 표기는 `bg.casaTougaard = {name,B,C,D,T0}` 에 남김; B > 0 → INNO `tougaard`(u3, C, D, T0) + `exact:false`.
  INNO Tougaard 는 B 를 높은 BE 끝에 맞춰 스스로 정하므로 CasaXPS 의 명시 B 결과와 다르다. U 2 의 D 는 INNO U2 식(T/(C+T²)²)에 없어 무시(표시).
- 명시 B 재현 시도(C1s, 'U 2 Tougaard 2866,1643,1,0' → 37823.6 / 14398.8 / −675.5): BG = (Linear 또는 y_lo) + B·Σ K(E−E')·j(E')·ΔE,
  j ∈ {y − y_lo, y − Linear, y − BG(자기일관)}, U2/U3 식, 영역/전체 합, 끝점 보정 — Area 33 785–41 428 / Max 14 359–14 594 (j = y 는 터무니없음), 어느 것도 아님. 미확인.

## 4. 남은 차이 (정의가 아니라 CasaXPS 수치 계산으로 보는 것)
- Lorentzian 이 섞인 모양의 넓이: LA(1,1,·) +0.8…+1.25e-3 (INNO 가 큼), SGL −0.6…−1.0e-3 (INNO 가 작음), LA(2,2)·LA(1.53,2.43) +1.2…1.9e-4, GL(30)·GL(30)T(2) ≤ 1.3e-5.
  정해진 F 단위·절대 에너지 꼬리 자르기, 표 + 선형 보간(간격 0.005–0.08 F), 약한 1/d^γ 가중을 시험 — 부호와 크기를 함께 맞추는 것은 없었다.
- 정확한 모양에서도 CasaXPS RMS 가 0 이 아님(GL(30) 8.3, GL(30)T(2) 6.8, LA(1.53,2.43) 15.7 vs 여기 12.4) — CasaXPS 의 모양 계산(수치 합성곱/표)에서 오는 바닥.
- CasaXPS fwhm(대칭 모양)은 실제 FWHM 보다 1.6–5.6e-4 작음.
- GL(30)T(2) 의 DoF 337 (자유 매개변수 3 이면 338): CasaXPS 가 T 모양에 매개변수 하나를 더 세는 것으로 보임 — 미확인.
