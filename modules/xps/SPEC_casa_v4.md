## 3. CasaXPS 'fwhm' 숫자·asym — 하나의 규칙 (v3 의 경험 δ 대체)
**x̂** = 성분 원점에 맞춘 격자 k·d (**d = F/40**, DS 는 wL/40) 에서 가장 큰 마디 k 와 k±1 을 지나는 포물선의 꼭짓점, 높이 y\* = 꼭짓점 값;
a < x̂ < b = y\*/2 교차점 (a 낮은 BE), **l = x̂ − a, h = b − x̂ → fwhm = 2·min(l, h), asym = 1 − l/h**.
- 꼭대기가 매끈하면 x̂ = 실제 최댓값 (차 O(d²)) → v3 의 Hw 와 같음. 꺾인 꼭대기(LA α≠β, n 0: 원점에서 곡률 −8α / −8β)는 꼭짓점이
  **δ = d(β−α)/(2(α+β))** 만큼 꼬리 쪽으로, 한쪽이 평평한 GL/SGL T(k) (1 − c·t³) 은 δ ≈ d(1−kd)/(2(1+kd)) ≈ 0.011 F — v3 의 경험값 0.0025 F·0.011 F 를 같은 d 하나로 설명.
- d 를 판독마다 풀면: fwhm 에서 0.0236–0.0249, asym 에서 0.0249–0.0257 (LA 3 쌍·GL T 3 개) → **1/40**.
- '쪽'·부호: LA(2.43,1.53,0) (꼬리 낮은 BE) → 2·(높은 BE 쪽) = 0.866770 (+1.8e-4), asym = 1 − l/h = −0.2950 (−0.2944). 'low-BE 쪽' 규칙이면 1.138 (+31 %) → 기각.
  ST(1.7)GL(30) 은 높은 BE 쪽이 더 좁아(h < l) 역시 2h, asym −0.0112 (−0.0131).

## 4. ST(μ) — 모양·위치·폭 정함 (Round 4–6, 16 판독)
**규칙**: K = 바탕 모양(ST 없이, n 의 ⊗G 포함)의 FWHM / F, D = K·F/40.
CasaXPS 의 ST 모양 = F(x)·[Φ(x − D/2) + A/μ] (Φ = ∫_{−∞}^{x}F, 높은 BE 쪽으로 쌓임; Cookbook p. 66 의 ∫_x^∞ 를 마디 D 의 배타 직사각형 합으로 계산한 꼴 — Shirley 와 같은 꼴),
넓이 1 은 그 모양의 수치 적분으로. **CasaXPS pos = 바탕 원점 + D·k\***, k\* = 마디 k·D (바탕 원점에 맞춤) 중 값이 가장 큰 것. 다듬기 없이 마디에 놓으므로 pos − 최댓값이 ±D/2 안에서 μ 에 따라 톱니처럼 바뀜
(Round 5 에서 '부호가 바뀌는' 것처럼 보인 원인). fwhm·asym 은 §3 규칙을 이 모양에 (포물선 마디 간격 D).
