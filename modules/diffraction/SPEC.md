# INNO Analytics — Diffraction 탭 SPEC v1.1 (2026-10-17)

보기 키 `lattice` 를 그대로 쓰고 탭 이름만 **Diffraction** (휴대폰 `Diffr.`). 모드 셋:

| 모드 | 내용 |
|---|---|
| **FFT (HRTEM)** | 기존 Lattice FFT 화면 그대로 (renderLattice) — 실공간 영상의 d-spacing·역FFT |
| **SAED** | 회절도(스폿·링) 자동 읽기 → 보정 → 상 찾기 · 수동 비교 · 보정 저장 · 내보내기 |
| **Phase DB** | 결정상 목록(내장·연구실 공유·이 기기), CIF 가져오기, 직접 입력, 검증·이력, 보정 목록 |

모드는 파일에 따라 자동: 역공간(1/nm) 교정 또는 DM `Operation Mode = DIFFRACTION` → SAED, 실공간 교정 → FFT, 교정 없음 → 파일 이름(diff·SAED·SAD) → 밝기 분포(중앙값/범위 < 0.15 = 회절도). 사용자가 고르면 그 파일 동안 유지.

## 2. 패턴 읽기 (diff_pattern.js)
- **덧그림**: 최댓값 97 % 이상 성분 중 가로 막대(꽉 찬 막대 / 속 빈 테두리 = REDI 예제형) = 스케일바, 가는 획 = 글자 → 상자째 가림, 막대 위 이름표 자리도 가림. 스케일바 이름표 숫자는 OCR(§3b)로 읽어 미리 채우고 사용자가 확인.
- **빔스토퍼**: 배경 중앙값 25 % 보다 어둡고 큰(≥ 0.2 %) 성분, 4 px 넓힘.
- **스폿**: 가우스 차(σ, 6σ; 큰 σ 는 상자 흐림 3 번) → **국소 잡음 지도**(칸별 MAD, 쌍선형) 의 k 배 넘는 국소 최대 → 배경 뺀 무게 중심. 영상 전체 한 잡음값이면 밝은 가운데에서 거짓 스폿이 생긴다(합성에서 확인 후 고침).
- **포화**: 최댓값과 정확히 같은 화소 4 개 이상 덩어리 = 스폿 하나(고원 중심, 세기 하한). 8-bit 내보내기의 직접빔·강한 반사.
- **중심**: Friedel 짝 중점 투표 + 큰/밝은 스폿 후보 → 거울 짝으로 다듬어 짝 수로 고름. **2D 격자는 격자 벡터 중점에도 반전 중심이 있어** 짝만으로는 직접빔과 반 격자점을 못 가른다 → 원점은 스폿 위(직접빔)거나 빔스토퍼 뒤여야 한다(실측 Fe-Cr: 반 격자점 (542,660) 대신 직접빔 (467,532)). 사용자가 찍은 중심은 근처(5 %·30 px) Friedel 중심으로 다듬는다.
- **격자**: 짧은 벡터·차 벡터 쌍 → 뚜렷한 스폿(SNR ≥ 9) 의 √I 가중 설명 비율 최대의 92 % 이상 중 가장 성긴 격자 → 안쪽부터 넓히며 최소제곱(중심 포함) → **방사 왜곡** v = p(1+k|p|²) 선택(잔차 36 % 이상 줄 때, k 는 잔차 제곱합 포물선 탐색) → Gauss 축약 REDI 규약 |R1| ≤ |R2|, ∠R1·R2 ≥ 90°, R3 = R1+R2(짧은 대각선). 불확도 = s²(XᵀWX)⁻¹.
- **여러 격자**(fitLattices): 센 스폿 위주(I 가중)로 첫 격자, 남은 뚜렷한 스폿으로 다음 격자(중심 고정). 화면에서 'Use spots: Strongest N' 으로 부분 집합.
- **링**: 줄인 영상에서 방위 평균 프로파일이 가장 날카로운 중심(이웃 빈 차이²·화소 수/세기) → 센 링 4 개의 광선 점(360) 타원 맞춤(Fitzgibbon 1999) 가중 평균 → 타원 보정 방위 적분(단축 기준) → 배경(구간 최솟값 이동 평균) → 국소 잡음 문턱 + 돌출(prominence) 봉우리, 포물선 부화소 → 넓은 봉우리·빔스토퍼 가장자리 표시.

## 3. 상 찾기 (diff_index.js)
- **정대축 2D 격자**(DC.zoneBasis): [uvw] 평면의 정수 기저 → 허용 반사(공간군 소멸 아님, |F|² > 10⁻⁴ 최대)가 만드는 격자(HNF) → 축약. 이중 회절 자리는 이 격자 점이라 저절로 포함.
- **스폿 순위**(rankSpots): FOM = (길이비, 각) χ² (+ 보정 쓰면 길이) / 자유도. R1≈R2 면 두 순서. 상위 80 개 검증 → Score = FOM + 5·Forb + (1 − ρ) + 3·Miss.
  ρ = 관측 스폿 세기 ↔ 운동학 |F|² Spearman, Forb = 운동학적 0 자리의 관측 세기 비율, Miss = 관측 범위(영상 안·가리지 않은 곳) 안 강한 예측 반사 중 안 보이는 세기 비율. 원자 좌표 없는 상은 Score = FOM + 1.
- **링 순위**(matchRings): 센 관측 봉우리 3 × 센 예측 링 → κ → 짝짓기(±1.2 %) → 가중 최소제곱 축척 → Score = 설명 비율 × (1 − 빠진 강한 링) × exp(−어긋남/허용) × (1+ρ)/2, ρ = 높이 ↔ m|F|²/g².
- **보정을 순위에 쓰는 때**: 저장한 표준 보정·직접 넣은 값만(Auto). 파일 태그·스케일바는 카메라 길이 공칭값이라 수 % 틀린다 — REDI 설명서 예(3 % 교정 오차로 Fe3O4 가 2 위)와 실측 Au(DM 태그 9 % 작음)에서 확인. 그때는 보정 없이 순위, κ(= 예측 g ÷ 측정 g)만 초록(허용 안)/주황으로.
- **아핀 보정**(calibrateAffine): 표준 패턴의 R1·R2 ↔ 예측 g1·g2 → T(px→1/nm) 극분해 → 평균 축척·찌그러짐·방향. 링 표준은 타원비·방향. 저장한 보정은 격자를 '찌그러짐 없는 px' 로 고쳐 비교.
- **수동 비교**(REDI 수동 해석): 상 + R1·R2 hkl → d·각·정대축·κ, 'Suggest hkl' = 측정 d·각에 맞는 hkl 쌍.

## 3b. v1.1 — 큰 영상 · 동역학 세기 · 스케일바 숫자 읽기
- **큰 영상**: 긴 변 > 1024 면 f×f 평균으로 줄여(≤ 1024) 덧그림·빔스토퍼·스폿·중심·링을 찾고, 원래 해상도에서 스폿 무게 중심(둘레 고리 중앙값 배경, 두 번)·직접빔·Friedel 중심·격자·링 타원(줄인 타원에서 출발, 광선 점·방위 적분 1 회)·스케일바(막대 상자를 잘라 다시)를 다듬는다. 표시 캔버스는 2048 px 넘으면 블록 최댓값으로 줄임.
  2048² Si 스폿 3.5 → 1.0 s · 4096² 9.8 s/415 MB → 1.1 s/212 MB · 2048² Au 링 7.0 → 2.0 s · 4096² 17.6 s/428 MB → 2.6 s/244 MB. 원래 해상도 전체 계산과 R1·R2 0.05 %, 링 축척 0.05 % 안(test_real).
  링 중심 목적 함수를 화소 배열로(1.3 → 0.18 s), 백분위 한 번 정렬, 방위 적분 증분 계산.
- **동역학 세기**(`diff_dyn.js`, Bloch-wave ZOLZ — docs-dyn.md): U_g = γF_g*/(πΩ), Bethe 퍼텐셜(Zuo & Weickenmeier 1995), 자체 tred2+tql2, 흡수 선택, 두께 10–80 nm 평균(SAED 조리개 안 두께 섞임). 검증: 두 빔 Pendellösung 3×10⁻¹⁵, 소멸 거리 Hirsch 표 14 반사 5.2 % 안, 얇은 결정 = 운동학 0.4 %, 독립 Bloch(gemmi+scipy) 1.3×10⁻⁶, 같은 ZOLZ 다중 슬라이스(abTEM 퍼텐셜) 0.1–2 %(Au 2.3 %), Gjønnes–Moodie 소멸(루틸 [001] (100)·ZnO [110] (001)·P2₁/c·Y2O3) 10⁻²⁶ 이하, 기울이면 생김. 120 빔 10 ms.
  상 찾기: 상위 12 후보를 동역학 세기로 다시 채점 — ρ = 관측 ↔ 두께 평균 Bloch 세기(포화 스폿 제외), Forb = 동역학적으로도 0 인 자리(ZOLZ 경로 없음 1, GM 소멸 0.3, 이중 회절 가능 0), Miss = 동역학 강한 반사 중 빠진 것. 화면 'Intensities: Dynamical / Kinematic'.
  합성 Si [011](동역학 세기, (200) 이중 회절 스폿 있음): 운동학 채점은 Forb 23.8 % 벌점·ρ 0.58 → 동역학 Forb 0 %·ρ 0.98, 점수 1.605 → 0.017.
  한계: HOLZ 없음(3D 다중 슬라이스 대비 Si 1 %, Fe 22 %, Au 76 % — 순위 상관은 대부분 0.94–0.999), 정확한 정대축 가정(GM 자리는 1–2 mrad 기울면 수 % 생김 → 벌점 0.3).
- **스케일바 이름표 읽기**(`diff_ocr.js`, docs-ocr.md): 막대 둘레만 보고 바탕 보정 → 문턱 세 번 → 글자 후보(Å 고리·붙은 글자·끊긴 조각) → 12×18 틀(고딕 3 가족 2 509 개) 최근접 + 가로세로비·구멍·기준선 → '수 + 단위' 문법 동적 계획 → 값 사전(1·2·5×10ⁿ) 벌점 → 로지스틱 확신도(조정은 시험과 다른 seed·글꼴 2 450 장).
  시험 780 장(따로 둔 글꼴 포함): 98.7 %, 확신 ≥ 0.9 에서 오답 0.14 %, 실측 Fe-Cr "5 1/nm" 확신 1.00('SAD 1' 무시), 2048² 20 ms. 어두운·흐린·속 빈 막대도 OCR 쪽 막대 찾기가 받는다. 화면: 값에 미리 채우고 확신 < 0.9 면 확인 요청, 실공간 단위면 경고. 한계: 명조·이탤릭·여러 줄, 아주 작은 위첨자 ⁻¹, mm·mrad 단위.
- **ρ 는 포화 스폿을 뺀다**(세기 하한) — 4 개 미만이면 중립(0.5).
