# AFM and Image Analysis tests

These are test-only dependencies; none are required by the application at runtime. Run commands from the project root with the injected `INNO Analytics.html` present. Use an isolated browser profile; the browser tests create and modify IndexedDB databases.

## Node and browser tests

Install Node.js and `playwright` in an isolated test-only Node directory. For example, `npm install --prefix <test-node-dir> --no-save playwright@1.62.1`, then set `NODE_PATH` to `<test-node-dir>/node_modules`. Set `INNO_CHROMIUM_PATH` to an existing Chromium/Chrome executable to reuse it; on the verification machine the successful value was `C:\Program Files\Google\Chrome\Application\chrome.exe` (Chrome 156.0.8078.80). Otherwise leave it unset and install the browser revision matching the installed Node Playwright, with `PLAYWRIGHT_BROWSERS_PATH` pointing to the browser directory. Browser revisions for different Node and Python Playwright versions are not interchangeable.

```powershell
node modules/image/test/test_browser_config.js
node modules/image/test/test_img.js
node modules/image/test/test_afm.js
foreach ($f in @('test_afm_quant.js','test_afm_level.js','test_afm_endpoint.js','test_afm_profile_nan.js','test_ibw_precision.js','test_ibw_curve.js','test_numeric_integrity.js','test_numeric_snapshot.js','test_numeric_stack.js')) { node "modules/image/test/$f"; if ($LASTEXITCODE -ne 0) { throw "$f failed" } }
$tests = Get-ChildItem modules/image/test -Filter '*.js' | Where-Object { $_.Name -match '^(test_(afm|ibw|numeric).*_ui|test_ibw_default_chrome|test_ibw_original_default|test_ibw_single_writer)\.js$' }
foreach ($f in $tests) { node $f.FullName; if ($LASTEXITCODE -ne 0) { throw "$($f.Name) failed" } }
```

`test_numeric_snapshot.js` additionally requires Python and NumPy for independent binary comparison. `test_ibw_curve.js` uses the 14 synthetic files in `curve_fixtures/`; they can be regenerated by `python modules/image/test/gen_ibw_curve_fixtures.py`. The three `probe_file_*` tests require a separate `lock-probe-copy.html` in the project root and test browser-specific file-origin behavior. They are environment probes, not a general guarantee about every browser. Tests named `*_default*` must use the actual browser under assessment; a Playwright Chromium build does not establish installed Chrome behavior. Tests explicitly passing `--allow-file-access-from-files` do not represent Chrome's default file permissions.

### Optional file-origin probes

The default suite does not run the three probes. To run them in an isolated test workspace, first ensure no file already exists at the test-copy path; this command refuses to overwrite one. Run from the project root:

```powershell
$probeCopy = Join-Path (Get-Location).Path 'lock-probe-copy.html'
if (Test-Path -LiteralPath $probeCopy) { throw "Refusing to overwrite existing file: $probeCopy" }
[System.IO.File]::Copy((Join-Path (Get-Location).Path 'INNO Analytics.html'), $probeCopy, $false)
foreach ($f in @('probe_file_indexeddb_scope.js','probe_file_web_locks.js','probe_file_web_locks_different_path.js')) { node "modules/image/test/$f"; if ($LASTEXITCODE -ne 0) { throw "$f failed" } }
```

Afterward, inspect `$probeCopy` and confirm it is the test-only copy you created. Remove it only after that explicit confirmation; the following command prompts before deletion:

```powershell
Remove-Item -LiteralPath $probeCopy -Confirm
```

### Reference availability and skipped comparisons

`test_img.js` and `test_afm.js` may exit with status 0 while reference or measured-data comparisons were skipped. Inspect their complete logs for `건너뜀` and other skip messages, record which reference datasets were present, and report the actual comparison and pass/fail counts. A successful exit alone is not evidence that ImageJ or real AFM data were compared. `test_img.js` skips its ImageJ section when `modules/image/ref/data` is absent; `test_afm.js` skips a dataset when its `truth/truth.json` is absent.

The ImageJ section of `test_img.js` intentionally skips six `Count` cases. In the isolated test workspace, `node test-tools/test_count_from_imagej_lists.js` separately compares the six Count outputs with row counts of ImageJ List results recorded in `modules/image/ref/data/manifest.json` and its input `.f32` files. It requires that generated reference data and the helper exist in the same layout; it does not launch ImageJ again. The existing references were generated using ImageJ 1.54u9, so report that version. This helper and the large generated reference data are **test-only and excluded from the application integration list**; retaining or adapting them separately is necessary to reproduce this additional check. In the recorded run all six matched: 278, 30, 93, 29, 165 and 30.

## Optional Fiji browser regression (Windows)

`ui_img_fiji_windows_test.py` needs Python Playwright, NumPy, tifffile, Java, ImageJ `ij.jar`, Fiji's AnalyzeSkeleton plugin and its compiled `SkelDriver`, the existing `test/io` fixtures, and ImageJ reference data under `modules/image/ref/data`. Supply test-only files outside the runtime. `INNO_TEST_ROOT` sets the base used for `test-tools`; `INNO_TEST_TOOLS`, `INNO_IMAGE_TEST_DIR`, `INNO_IMAGE_REF_DIR`, and `INNO_TEST_TMP` override individual locations. Java must be on `PATH`. The script accepts an HTML path and an output directory and honors `INNO_CHROMIUM_PATH` or the matching Python Playwright browser installation. On Windows a short ASCII path or temporary drive mapping may be needed for ImageJ; supply it through environment variables rather than modifying the script.

```powershell
python modules/image/test/ui_img_fiji_windows_test.py <html-path> <output-dir>
python -c "import json; p=json.load(open(r'<output-dir>/ui_result.json',encoding='utf-8')); bad=[c for c in p['checks'] if not c[0]]; print('checks',len(p['checks']),'failed',len(bad),'console errors',len(p['errors'])); assert len(p['checks'])>=69 and not bad and not p['errors']"
```

Always inspect the JSON: this legacy script can exit successfully even when a check fails. `SKIP_SKEL=1` or missing Fiji dependencies skips the Fiji comparisons; do not report that as a full Fiji run. The separately retained `ui_img_windows_test.py` is an older path-specific diagnostic and is not part of this portable test set. Reference data, real measurement files, test tools, browser installations, generated output and temporary drive mappings are not application source or release artifacts.

Verification here used Node Playwright 1.62.1 with the explicit existing Chrome path; Python Playwright 1.64.1 used its own installed browser. The Node default browser could not be tested because the matching `chromium_headless_shell-1234` was not installed; the installed `-1248` belonged to the Python environment. No duplicate browser was downloaded.
