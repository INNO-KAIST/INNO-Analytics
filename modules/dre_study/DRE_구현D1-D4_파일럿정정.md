## ⚠ 기획서 v0.1 §1 파일럿 정정

v0.1 의 파일럿 수치는 **결함 있는 Python 정상상태 풀이**로 얻은 것이다.

**결함**
- d₃=0 을 2차식의 작은 근으로만 소거했고, 판별식이 음수인 구간을 0 으로 잘랐다.
- 그 결과 문턱보다 높은 파워(≳ 8 kW/cm²)에서 **가짜 근**을 돌려줬다.
- 이 결함은 이번에 JS 엔진을 scipy LSODA 장시간 적분과 독립 대조하다가 발견했다.
- 수정한 `modules/dre_study/fwd.py`·`pa3.py` 는 JS 와 10⁻¹⁰ 까지 일치한다.

**정정**

| v0.1 주장 | 정정 |
|---|---|
| log 매개변수 다중 출발 성공률 45–53 % | **엔진 결함(잔차 Jacobian 의 ln10 인자 중복)을 고친 뒤 90–100 %** (Lee Sample 4, 출발 40). 참값 무작위 30세트에서는 출발 20개로 **30/30** 전역해에 도달했다(출발점당 중앙값 60 %). |

| σ_ESA 만 결정, 나머지 1.75–3 decade 열림 | **결론은 더 강해졌다.** S-curve 하나로는 매개변수 오차 중앙값이 1.4–2.5 decade 다. 원인은 모든 속도·단면적을 동시에 바꾸는 방향이 배율 s 에 흡수되는 것(FIM 최소 고유값 ≈ 0). |

| 0.5 s 적분 → 7 kW/cm² 에서 83 % | 유지 (JS·scipy 모두 0.834, t₉₅ = 0.639 s) |
| 최대 기울기 26 (Sample 4) | 잘못된 값. 올바른 값은 **42.5 @ 6.8 kW/cm²** (1 kW/cm² 격자에서 27) |

**"지역 최소에 갇힘"에 대한 수정된 결론**
- 원인은 두 가지다.
  - (a) 부정확한 기울기와 정상상태(차분 도함수, 0.5 s 적분, 선형 매개변수)
  - (b) 식별 불가능한 평평한 골짜기(χ² 는 같은데 값이 decade 단위로 퍼짐)
- (a) 는 엔진으로 해결했다.
- (b) 는 **데이터로만 해결**된다: 절대 시간 정보와 농도 계열.

## 구현

**위치**
- `E:\Develop\INNO Analytics\modules\dre\` (src, test)
- 주입기 `modules\inject_all.py` 가 Energy Diagram 과 DRE 를 함께 주입한다. 멱등이며, 원본과 주입본 어디에 돌려도 결과가 같다.
- `energy_diagram/build/inject.py` 는 더 쓰지 않는다.

**`dre_core.js`** (DOM 없음, 메인·Worker·node 공용)
- 모델: 이온 종별 점유(합 1), 과정 abs/dec/et. 계수는 식으로 쓴다(예: `k31*c^2`). et 는 scale "x"(평균장 몰분율) 또는 "none".
- 정상상태: 앞 해에서 Newton + 선 탐색으로 풀고, 실패하면 암시적 Euler 의사시간(dt 기하 증가) 후 Newton.
- 스윕: up/down 연속. 가지 점프와 히스테리시스가 자연히 나온다.
- 감도: IFT 로 정확히 구한다.
- 동역학: TR-BDF2 + 단계 배가. 상승·감쇠 시간은 목표에 도달하면 끝낸다.
- 관측: 첨두 또는 가우시안 빔 적분(거듭제곱 구간 적분 + Richardson).
- 피팅
  - 잔차: log 잔차, 데이터셋별 배율 닫힌해 소거, 검출 하한 아래는 절단 잔차
  - 최적화: LM(Nielsen) + LHS 다중 출발
  - 진단: 프로파일 가능도(warm start), FIM(Jacobi), AICc
  - 시간 데이터 잔차는 차분 Jacobian 이라 느리다(S-curve 대비 약 10배).

**`dre_ui.js`**
- 모델: Lee 템플릿 / Energy Diagram 가져오기(자리표시 값 표시)
- 매개변수 표: 값, 고정, 시료별, 탐색 범위, 출처
- S-curve: 올림·내림, 데이터 겹침, 기울기
- 시료·데이터: CSV·붙여넣기, 채널 매핑, 배경σ·k·곱잡음, 방향, 합성 데이터
- 피팅: Worker, 진행 막대, 중단
- 결과: 최적값, 95 % 구간(열림 표시), waterfall, 프로파일 그래프, FIM 방향, 참값 대비
- 내보내기: CSV / JSON
