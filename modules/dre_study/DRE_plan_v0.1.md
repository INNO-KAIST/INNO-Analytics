## 0. 한 줄 요약

**DRE 피팅이 지역 최소에 갇히는 원인은 알고리즘보다 문제 설정에 있다.**
1. 정상상태 S-curve 한 개로는 식별되지 않는 방향이 구조적으로 존재한다.
2. 나머지 방향도 10자릿수에 걸쳐 sloppy 하다.

따라서 해법은 세 가지를 **함께** 쓰는 것이다.
- **정식화**: log 매개변수, 무차원화, 스케일 계층 소거
- **데이터 결합**: 농도 계열 전역 피팅, rise/decay
- **진단**: multistart waterfall, profile likelihood

전역 최적화기만 바꾸는 것으로는 해결되지 않는다.

## 1. 파일럿 계산으로 확인한 것 (합성 데이터, 참값을 앎)

**설정**
- 모델: Lee et al., Nature 589, 230 (2021) 공개 코드의 Tm³⁺ 3준위 모델. "Sample No. 4" 값(8 %)을 그대로 옮겼다.
- 데이터: 0.3–60 kW/cm², 45점. 샷 노이즈, 5 % 곱 노이즈, 암전류 바닥 40 counts 를 넣었다.
- 자유 매개변수 7개: σ_GSA, σ_ESA, W₂,nr, W₃,nr, s₃₁, Q₂₂, Q₂₃ + 검출 배율 S
- 고정: W₂,r, W₃,r, β₃₂

| 확인 항목 | 결과 | 설계에 주는 의미 |
|---|---|---|
| 모든 rate·σ 를 같은 배수 k 로 곱하기 | 정상상태 n₃ 가 **완전히 같음** (상대차 1×10⁻¹⁵) | S-curve 만으로는 절대 시간 스케일이 **구조적으로** 정해지지 않는다. 절대 rate 하나를 고정하거나 시간분해 데이터가 필요하다 |
| 흔한 방식: 선형 매개변수 + 선형 잔차 + S 동시 | 무작위 60 출발 중 **0 %** 가 최적에 도달. 대부분 16회 평가 안에 멈춤 | "지역 최소 갇힘"의 대부분은 정식화 문제다 |
| log 매개변수 + log 잔차 | **53 %** 도달 | 필수 |
| + S 계층 소거 | **45 %** 도달, 시간 38 % 단축 | 속도 이득. 성공률은 비슷 |
| 최적해에서 매개변수 복원 | χ² 는 참값보다 **낮음** (0.025 vs 0.051). 그러나 W₃,nr 0.93 decade, W₂,nr 0.35 decade 어긋남 | 맞춤이 좋다고 매개변수가 맞는 것은 아니다 |
| profile likelihood (95 %) | σ_ESA 만 격자 간격(0.25 decade) 이하로 결정됨. 나머지 6개는 1.75–3 decade, 그중 W₂,nr·W₃,nr·Q₂₃ 등은 **한쪽 또는 양쪽이 열림** | 실질적 비식별 → 고정·사전분포·데이터 추가가 필요하다 |
| FIM 고유값 | 10⁻⁶·⁷ – 10³·⁹ (**10.6 자릿수**). 가장 sloppy 한 방향 ≈ 모든 rate 의 동시 스케일 | 스케일 대칭이 고정 radiative rate 로 '거의만' 깨져 있다 |
| 같은 S-curve 를 주는 두 매개변수 집합의 rise time (t₉₅) | 7 kW/cm² 에서 0.64 s vs 0.52 s. 전 파워에서 약 20 % 차이 | **rise time 데이터가 이 퇴화를 깬다** |
| Lee 코드의 '0.5 s 적분 = 정상상태' 근사 | 7 kW/cm² 에서 n₃(0.5 s)/n₃(∞) = **0.83** | 임계점 바로 그 자리에서 기울기가 왜곡된다. 정상상태는 적분이 아니라 근 찾기로 풀어야 한다 |

이 결과는 "검증은 참값을 아는 합성 데이터로" 원칙에 따른 것이다. 실측 S-curve 는 아래 V4 단계에서 반례·회귀 감시에만 쓴다.

## 2. 위치와 경계

- **INNO Analytics 의 새 탭 'DRE'**
  - 입력: Energy Diagram 에서 그린 과정 그래프(준위·GSA/ESA·ET/CR/ETU·MPR)를 모델 명세로 가져온다.

  - rate equation 모델은 물질 특이적이므로 일반 분석 코어에 넣지 않는다(기존 원칙).
  - Prism 의 S-curve 데이터는 **내보내기 파일(CSV/HDF5)로만** 받는다.

|---|---|---|---|
| A (권장) | 브라우저 JS + Web Worker | 기존 단일 HTML·오프라인 원칙 유지 | — |
| B | Python 참조 구현 | 검증용 | 앱 밖에서 돌아감 |

## 4. 매개변수화 — 자유도를 물리로 줄인다

1. **모든 양의 매개변수는 log₁₀ 로 둔다.** 파일럿에서 성공률이 0 % → 53 % 로 올랐다.
2. **복사 rate A_ij·분기비는 고정 또는 사전분포로 둔다.**
   - 출처: JO, 저농도 수명(Villanueva-Delgado 2016: τ(³F₄) = 12 ms, τ(³H₄) = 1.94 ms)
   - 이것이 스케일 대칭을 깨는 닻이다.
   - 문헌값이 2배씩 갈리므로(³F₄ radiative: Lee 코드 162.6 s⁻¹ vs Kwock 83.3 s⁻¹) **출처를 값과 함께 저장**하고, 선택을 사용자에게 보인다.
3. **MPR 은 개별 rate 로 두지 않는다.**
   - 호스트당 (B, α, ħω) + 준위 간격 ΔE 로 생성한다(에너지 간격 법칙, 온도 인자 [n(T)+1]^p).
   - 수십 개 rate 가 3개로 줄고, 온도 의존이 자동으로 따라온다.
   - 호스트 상수는 원문 확인 전까지 [unverified] 표지를 달고 사전분포로만 쓴다.
4. **ET 계열(ET/ETU/CR/BET)**
   - 형태: 계수 × 농도 스케일 함수 × 에너지 불일치 인자 exp(−β·δ)
   - 농도 함수는 선택지로 두고, 어떤 것을 썼는지 결과에 기록한다.
     - 평균장 선형
     - Lee 코드의 경험식(s₃₁ ∝ c², Q ∝ c³/(c²+4.3²))
     - Inokuti–Hirayama
   - 역과정은 **상세 균형**으로 묶는다: W_back = W_fwd·(g 비)·exp(−ΔE/kT).
5. **샘플별 자유 매개변수는 비방사 손실(k₂, k₃ 또는 셸 매개변수)로 한정한다.**
   - σ, ET 계수는 여러 샘플이 공유한다(전역 피팅).
   - Lee 2021 코드가 쓰는 방식이며, 식별성을 가장 크게 올리는 설계다.

## 5. 관측 모델 — 측정을 있는 그대로 쓴다

- **채널**
  - y_ch(P) = s_ch · A_rad,ch · n_emit(P) + b_ch
  - (s_ch, b_ch) 는 매개변수가 정해지면 닫힌해로 계층 소거한다(Loos, Bioinformatics 34, 4266 (2018)).
  - 다채널(800/475/450 nm 등)을 동시에 피팅해도 gain 을 몰라도 된다.
- **빔**
  - 단일입자: 첨두 강도
  - 앙상블·필름: 가우시안 빔 공간 적분 ∫n(I)/I dI
  - **강도 정의(첨두/FWHM/평균)를 메타데이터로 강제**한다. 정의 차이는 σ 로 그대로 흡수되기 때문이다.
- **배경·검출 하한**
  - 기저선을 0으로 치환하지 않는다(기존 원칙).
  - 암전류 3σ 이하 점은 버리지 않고 **절단(censored) 우도**로 넣는다. pre-avalanche 영역도 정보다.
- **노이즈 모델**: 샷 + 곱(비율) + 배경 3성분. 노이즈 매개변수는 동시에 추정한다(Raue 2013 권고).
- **스윕 방향·체류시간**: up/down, dwell time 을 데이터에 기록하고, 해 가지 선택에 쓴다(§6).
- **결측**: 중단·결측 데이터는 NaN 으로 둔다(0 금지).

## 6. 수치 엔진

- **정상상태 = 근 찾기**
  - 작은 모델(L1): 파일럿처럼 n₃ 를 닫힌 형식으로 소거하고, 1차원 근을 **전부** 찾는다. 다중 정상해가 있어도 빠짐없이 나온다.
  - 일반 N준위: Newton + 해석 Jacobian + **pseudo-arclength continuation**(파워를 매개변수로)
    - fold = switch-on/off 문턱을 직접 찾는다.
    - Jacobian 고유값으로 안정성을 판정한다.
- **해 가지 선택**: up-sweep 은 하위 안정 가지, down-sweep 은 상위 안정 가지.
  - 열 없이도 bistability 가 가능하다(Skripka et al., Nat. Photon. 19, 212 (2025)).
  - 초기값 따라 아무 근이나 고르면 목적함수가 불연속이 되어 최적화가 깨진다.
- **동역학(rise/decay)**
  - stiff 적분기(BDF/Radau, 해석 Jacobian)를 쓴다.
  - 임계 부근 critical slowing down 때문에 **적분 종료를 '시간'이 아니라 '정상해와의 거리'로 판정**한다.
- **감도**: forward sensitivity 로 기울기를 계산한다. 차분 도함수는 가짜 국소해를 만든다(Raue, PLoS ONE 8, e74335 (2013)).

## 7. 피팅·진단 파이프라인

1. **전처리**: 배경·노이즈 모델, 절단 점 표지, 강도 정의 확인
2. **다중 출발**: log 공간 Latin hypercube, 기본 200개 → gradient 국소 최적화(TRF/LM, 경계)
   - 필요하면 전역 단계(scatter search 또는 CMA-ES)를 앞에 붙이되, **반드시 국소 정밀화와 결합**한다.
   - 근거: Villaverde, Bioinformatics 35, 830 (2019) — 하이브리드가 최상, 순수 확률적 방법은 열세
3. **waterfall plot**: 출발점별 최종 χ² 를 정렬해 보인다.
   - 전역해 도달 비율과 '계단' 수(서로 다른 국소해)를 보고한다.
   - 이것이 "지역 최소에 갇혔는가"에 대한 **정량 답**이다.
4. **profile likelihood**(Raue, Bioinformatics 25, 1923 (2009)): 매개변수마다 95 % 구간과 '열림' 여부를 표시한다.
   - 열린 매개변수는 결과 표에서 **값 대신 하한/상한**으로 보고한다.
5. **FIM 고유 분해**: sloppy 방향을 매개변수 조합으로 보인다(예: "모든 rate 동시 스케일"). 무엇을 더 재야 하는지 제안한다.
6. **모델 선택**: 중첩 모델 AICc/BIC. MBAM 식 축약 후보를 제시한다(예: Q₂₂→0, 중간 준위 접기).
7. **불확도**: profile 기반 구간을 기본으로 하고, 부트스트랩 또는 MCMC 는 선택형으로 둔다.

**결과 보고 원칙**
- 식별 가능한 무차원 조합을 먼저 보고한다: σ_E/σ_G, s₃₁/W₂, 문턱 강도 I* = W₂hν/σ_ESA 등.
- 절대값은 고정한 닻(어떤 radiative rate 를 어디서 가져왔는지)과 함께 보고한다.

## 9. 결정이 필요한 것

1. **계산 위치**
   - A: 브라우저 JS + Worker (권장). 단일 HTML·오프라인 원칙 유지.
   - B: Python 백엔드 병행
2. **첫 구현 범위**
   - L1(Tm 3준위) + 일반 엔진 골격까지 (권장)
   - 또는 처음부터 L2 자동 생성까지
3. **보유 데이터** — 각 항목 유무에 따라 V4 설계와 식별 가능한 매개변수가 달라진다.

   - (b) 같은 조성의 **농도 계열** S-curve
   - (c) rise time 또는 decay (특히 ³F₄·³H₄ 수명)
   - (d) up/down 스윕 기록
4. **첨부 제안하신 실측 S-curve**: V2 합성 검증을 통과한 뒤 V4 에서 받는 순서를 권한다(실측에 모델이 맞춰지는 것을 막기 위해).
